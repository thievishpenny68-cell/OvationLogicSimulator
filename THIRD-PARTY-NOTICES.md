# Third-party components

SheetJS Community Edition 0.20.3 mini is included locally for reading .xlsx input waveforms. License: Apache-2.0; full text is in src/vendor/xlsx.LICENSE.txt. No network request is needed at runtime.

- Official script: https://cdn.sheetjs.com/xlsx-0.20.3/package/dist/xlsx.mini.min.js
- SHA-256: 0cb353f830d7288385492c83d277b058ddeac664ca51cf1393aa1fd3e2b70939
- Official installation documentation: https://docs.sheetjs.com/docs/getting-started/installation/standalone/
- Cell/reading API documentation: https://docs.sheetjs.com/docs/csf/cell/ and https://docs.sheetjs.com/docs/api/parse-options/

The two-column template was authored with the bundled artifact-tool and contains ordinary values. The artifact-tool is not distributed or needed to use the simulator.
