# 暂时禁用模块

在右侧属性勾选“禁用此模块”，或用顶部画布工具的“禁用”点击模块。模块变灰并显示“已禁用”。“恢复”工具或取消勾选可以恢复。适用于输入、输出、算法、未支持块和导入的用户宏；原有模块、参数、初态及连线都保留。一次修改可撤销、重做，保存工程后仍保留禁用状态。

禁用是软件执行范围设置，不是 Ovation 算法引脚或控制器功能。修改范围会暂停运行并清除旧轨迹；再次运行从各参与块的已配置初态开始，不沿用禁用前的内部状态。

## 连接与依赖

被禁用的输出没有数值。所有依赖其输出的下游模块自动显示“依赖暂停”，不执行、不输出，也不记录虚构的零值或 FALSE。这个规则逐级传播；汇合模块只要有一个输入依赖暂停，就整体暂停，即使该输入在算法中可选。独立支路仍按原扫描规则运算。

对于尚待核对、但已经定位源和目标模块的候选连接，也按可能依赖暂停目标，避免把未接通的禁用源当作不存在。这不把候选线升级为已确认的逻辑连线；原始待核信息仍完整保留。

绑定同一 `packedPoint` 的 LP 共享字读写块作为一个依赖组处理：禁用其中一个，其余成员及下游一起暂停，避免改变共享字时序后仍声称运行原逻辑。

恢复上游后，依赖暂停自动解除；人工禁用的下游仍保持禁用。对“依赖暂停”模块使用恢复工具不会越过上游强制启用它，状态栏会提示先恢复上游。

## 检查、显示及记录

运行前只检查参与执行的子图及其来源问题；禁用部分的参数、未支持算法、未展开宏、待确认连接不会阻挡独立子图，但这些信息仍完整保留，恢复后会重新检查。工程结构、周期、规则版本等全局错误仍会报错。

有效执行顺序是原明确顺序的参与块子序列。已有有效确认可继承为这个子序列；记录中的`execution.confirmation.reviewedScope`保留真正核对过的节点集合和结构签名。恢复只可继承到这份已核对且结构未变的范围：仅核对部分图后恢复更多节点、或禁用期间改变引脚类型及连接结构，需要重新确认。原本没有确认、已经过期或有任务冲突的计划不会因此变成已确认。算法、初值及数值验证规则不因禁用而放宽。

连接诊断如果只有来源键而没有节点号，会结合原候选及SVG物理路由按文件名和连接键定位其归属；只有已知属于暂停部分的诊断才暂缓。不相关文件、仍涉及活动目标的连接或无法确定归属的全局问题继续保留。

采用禁用功能的工程升级为版本3，并声明 `disableModel: dependency-closure-v1`，防止旧版引擎忽略禁用标志后运行整图。运行记录仍携带完整工程，另有 `manifest.executionScope` 列出人工禁用、依赖暂停及参与块；逐扫描快照只含参与块。复算要求执行范围与完整工程一致。
