# 辅助XML的结构核对与任务边界

产品0.6.2，核心0.5.0。依据为用户提供的真实ControlFunction XML结构；未取得编译格式完整规范，因此只保留明确原文，不解析未知位置参数的运行含义。

## 导入行为

同名XML可与SVG同时选入。对未被实际用作当前目标、宏实现或宏定义的XML，导入快照新增可选`auxiliaryDocuments`：文件名、关联状态、根标签及属性、全部元素/属性/直接文本、父子身份、指令列表、参数列表及空字段。编号和参数位置只表示文档中的顺序，不是控制器执行序号或引脚名。

无cb-classname的ControlFunction编译文件按ControlProgramInstruction/ControlProgramArgument记录结构列出，产生`COMPILED_PROGRAM_REVIEW_REQUIRED`。未知格式、无效XML和未关联来源分别提示；带Builder标记但未被实际采用的XML产生`AUXILIARY_BUILDER_NOT_APPLIED`或未关联提示，不能仅凭类型标记从清单消失。实际采用的XML实现/宏定义仍走既有解析，不重复当成未采用文档。

不会从function-name或argument的type/point、空值、算法编码、相同数值自动创建块、填参数、生成连线或确定初态。未解释元素保留并计数。原始文件仍保存在sources，核对快照不随人工确认改写成已解码。

## 任务声明

同名关联文档中的明确cb-task-id，以及编译/Builder根明确task-id，加入既有来源任务组。不同非空标识按来源冲突或多任务阻断，普通问题确认和扫描计划采用不能绕过；不同名的未关联XML不与当前图合并。任务号不推断周期，编译文档顺序不自动变为软件执行计划。

人工确认只记录核对依据，不表示这些位置参数已经得到算法语义。仍须核对当前图支持范围、已知连接、工况、初态、周期和顺序；其他核心错误保持阻断。

## 兼容与证据

新导入审计仍为schemaVersion1，增加可选XML字段和计数。新版本可读取没有这些字段的旧审计，保持旧快照不变；要获得新增XML核对/任务检查，需要重新导入原SVG及配套文件。重新导入会建立新工程，应先保存已有人工修复。不能将打开旧工程当作已重新解读其XML。

当前标准来源14FA.xml共46个元素、4条编译指令、41个参数记录；包括空point的记录全部保留。分母独立按原XML元素统计，导入、清单导出和JSON重开一致；原始文件SHA256不变。任务冲突、未知/未关联/无效XML、未采用Builder、损坏新审计及旧审计兼容均有回归。该证据不证明编译参数位置、实际指令调度或整个真实宏可准确运行。
