# INPUT / OUTPUT 外形与方向

0.50.0按用户附件重绘模拟器辅助输入、输出点：圆形外接一个分成两格的短条，条内留空，OUTPUT不显示附件中的A。模块类型、名称、当前值位于图形外，端子继续按LD方形、LA圆形、LP六边形及未定类型菱形区分。

选中INPUT或OUTPUT，在右侧“图形方向”选择：

|模块|选择|图形与可接线端|
|---|---|---|
|INPUT|左侧 · 向右输出|分格条在圆左，唯一OUT向右|
|INPUT|上部 · 向下输出|左侧形状顺时针旋转90度，OUT向下|
|OUTPUT|右侧 · 从左接入|分格条在圆右，唯一IN1从左接入|
|OUTPUT|底部 · 从上接入|分格条在圆下，唯一IN1从上接入|

方向完全由用户选择，不根据模块坐标自动切换。切换后实际端子、连线切线及探针接入点同步更新；不会增加OUTPUT输出端，也不修改已有端口绑定。文字保持正向，方便阅读。

打开examples/io-orientation.json可同时查看四种形式，以及数字量和模拟量的端子与读数。

方向保存在节点显示字段ioOrientation（horizontal / vertical）中，旧工程未包含该字段时默认INPUT左侧、OUTPUT右侧。支持工程保存重开及撤销/重做。完整工程指纹包含方向，计算投影剔除该字段，因此改变方向会保留运行记录、对照及未应用输入草稿；不改变输入规律、点类型、算法或时序。新建运行记录可按原完整复算流程核对。

同版本还调整输入设置：输入源选择条和波形编辑内容一起滚动；宽屏下左侧字段保持紧凑，波形预览使用右侧空白，靠区域右边排列。较窄窗口保持两列自适应，不增加横向溢出。
