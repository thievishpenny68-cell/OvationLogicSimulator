# 溯源恢复

画布工具中的“溯源恢复”用于只运行某些OUTPUT观察点所需的逻辑。

1. 点击工具后立即暂停运行，禁用页面上的全部逻辑模块。
2. 点击画布上的OUTPUT观察点，或它的IN1端子。程序恢复这个OUTPUT及其全部上游输入、算法和相关依赖。
3. 可继续选择其他OUTPUT，恢复范围累加。共用输入只恢复一次，未选分支保持禁用。
4. 按Esc、再次点击该工具或切换工具退出；当前禁用范围保留。开始运行也会退出工具，按当前范围从配置初态仿真。

这里的OUTPUT指终端观察点模块；普通算法的OUT输出脚不是选择对象。模式中的画布不选择、连线、删除或移动其他模块，仍可滚轮缩放、中键平移。添加模块需要先退出。每次重新进入模式都会重新全禁用。

每次进入和每次恢复都可单独撤销、重做。撤销/重做时自动退出工具，避免历史状态与当前操作模式混淆。保存工程保留各块禁用状态；工具模式本身只在当前页面使用。

## 依赖与准确性

- 逆向遍历全部已连接输入，不只取最短路径；反馈路径用已访问集合去重，不会无限追溯。
- 已定位源、目标模块的待核连接也纳入可能依赖，但不会自动变成已确认连接，相关报错仍需处理。
- 同一显式`packedPoint`的读写块一起恢复，并继续追溯各成员的输入，避免恢复读者后仍因共享字写者被禁用而暂停。
- 不展开或猜测用户宏的运算，不修补缺失参数、端口或未知源。恢复后继续执行原来的仿真检查。
- 扫描确认沿用[模块禁用规则](disabled-blocks.md)：已核对且结构未改的完整图可用于其子范围；只核对过部分图时，恢复更多范围须重新确认。

连线、来源记录、参数和初态保持。进入或恢复改变运算范围时清除旧运行轨迹；已应用输入波形按新一轮仿真的时间从零重新采样。
