# 手绘连线工具

0.57.0在顶部中间的“画布工具”加入“连线”。适用于需要自己安排走线路径的情况，原有拖端口和两次点选的自动布线仍可使用。

## 操作

1. 点击“连线”，再点击输出端或已存在的信号主线起笔。
2. 连续点击空白位置放置折点，预览使用横竖折线。空白点吸附10画布单位网格，靠近前一点的水平/竖直方向会对齐。
3. 点击目标输入端完成连接。也可先选输入端，放置折点后接到源输出或已有主线。
4. Backspace撤回一个放置点。Esc取消当前草稿，再按一次退出工具；点“选择”或其他工具也可退出。

完成一条后工具保持启用，可继续绘制下一条。未完成的草稿不写入工程；有类型冲突、目标已有驱动或尝试合并两个源时提示原因，原连接保持。

## 主线与分支

点击主线起笔或从输入端接入主线时，程序仍以源输出驱动目标输入，图形使用共享主线和新分支。实际三向接点显示实心圆点，公共主线只绘制一次，源数值框只保留一份。也可以从已存在的分支继续引出新分支。

不同信号仅几何交叉时没有圆点，也不会自动短接。观察探针、未解析的橙色导入线不能冒充已确定的逻辑信号源。若宏接口类型尚未确定，仍按既有自定义宏显示规则处理，不产生仿真输出。

## 保存与后续编辑

折线路径存于逻辑边的 `routing` 显示字段，保留原源端、目标端和针脚身份。保存重开、撤销/重做保持路径和分支接点；移动端点模块后重新接到实际端口，折点位置尽量保持。宿主分线被删除后，仍有驱动的其他目标会连接到剩余同源网络。

连线工具不增加算法规则或时间延迟。路径不参与仿真计算指纹，真实边的增加/删除仍按既有规则清除旧运行。示例：[manual-wire-branches.json](../../examples/manual-wire-branches.json)，可观察主线、分支及分支上的再分支。
