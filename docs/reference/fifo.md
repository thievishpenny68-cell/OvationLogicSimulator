# FIFO 数字事件队列

依据 REF_1100 §4.38，印刷页 161–162。IN1、RTAT、CLR 必接，IN2 至 IN16 可选。所有输入为 LD，OUT 为 LA，FLAG 为可选的 LD 输出。无整定参数。图例按手册保留 18 个左侧端子、右侧 OUT 和 FLAG，以及实心模拟量、空心数字量箭头。

每个事件输入的 FALSE→TRUE 将输入编号加入队列，同一拍多路上升沿按编号从小到大排列。持续高电平只记录一次，信号下降再上升时作为新事件记录。队列容量 16，满时额外事件丢弃。

RTAT 每次上升沿取出最早入队的编号。OUT 保持最后一次出队的编号，直到下一次 RTAT 上升沿或 CLR。空队列收到 RTAT 上升沿时 OUT 为 0。FLAG 表示队列是否非空，因此取出最后一项的那拍可以同时看到 OUT 为该编号、FLAG 为 FALSE。CLR 为 TRUE 时清空并忽略入队与出队。

## 软件起点与扫描边界

复位从空队列、OUT=0、FLAG=FALSE 开始。起点前 IN1–IN16 电平以位图配置，IN1 对应最低位，RTAT 有单独的起点前电平。手工新建预填全低，SVG 导入需要补齐这两项，运行时读取的队列和历史电平可在属性栏查看。CLR 保持为高时，模拟器跟踪当前电平，释放后仅接收新的上升沿。这是明确的软件约定，重复新沿入队也按每个事件独立处理。

手册没有指定入队与 RTAT 同拍时的执行先后。两种顺序得到相同 OUT 和队列时正常提交。结果不同时提示拆分到不同扫描，整拍回滚。例如空队列同时收到 IN1 和 RTAT 上升沿会停止。在同拍剩余容量不足时，保留按编号排列后能够装入的事件。强制 OUT 或 FLAG 只影响发布值，出队及队列状态继续按正常规则运算。

中文版出队段落有一处译作“最迟”，同段前文、先入先出名称和 Emerson 英文手册 R3-1100 §3-37 均以最早入队为准。目前验证依据为手册、手算轨迹和软件回归。

## 示例

打开 examples/fifo.json，按 100 ms 单步。第 1 拍 IN9 入队，第 2 拍 IN1 与 IN16 依次追加。第 3、5、7 拍分别出队 9、1、16。第 7 拍队列已空、FLAG 为 FALSE，OUT 仍为 16。第 8 拍 CLR 将 OUT 清零。examples/fifo-reference.json 提供逐拍队列、深度和输出对照。
