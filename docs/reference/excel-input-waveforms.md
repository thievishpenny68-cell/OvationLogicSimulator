# 从Excel导入INPUT波形

0.47.0新增“导入 Excel”“下载模板”，两按钮位于输入设置的同一行。支持本地未加密.xlsx，断网使用；无需安装Excel或服务器。

1. 选择一个已明确信号类型的INPUT，点击“下载模板”。模板只有“时间（秒）”“值”两列，三个节点为(0,0)、(0.35,1)、(0.7,0)。修改或追加行并保存.xlsx。
2. 点击相邻的“导入 Excel”选择文件。单工作表直接校验；多个工作表时明确选择。导入默认分段保持；模拟量已选分段线性时沿用线性。保持/线性互换保留节点。
3. 导入成功会显示文件、工作表与节点数，并立即预览。当前工程和运行记录保持；点击原有“应用参数”后才采用并清除旧运行。保存工程会保存采用的全部时间/值节点，原Excel文件由用户保管。

## 两列规则

- 第一列为非负有限秒数，按行严格递增。重复或倒序不自动排序/去重。可使用模板表头，也可不带表头；支持“时间/时间（秒）/time/time_s”和“值/value”等明确表头。
- 数字量只接受布尔TRUE/FALSE、数字0/1或相同文本；模拟量使用有限数值，并受当前正常Float32/零规则限制；LP为0～65535整数，可用明确0x十六进制文本。导入不会把任意非零数转TRUE。
- 全空行可以忽略，结果注明数量；缺半行会报A/B具体单元格。额外数据列、公式（包括已有缓存值）、Excel日期/时间格式、错误单元格、合并单元格明确报错。时间列按数值秒输入，不能用日期序号或HH:MM:SS代替。
- 单文件最多5MiB，最多5000个数据节点；超限整份拒绝，不截断。文件损坏或数据不合法时保留当前草稿和已应用配置。

文件读取期间继续手工改动、切换INPUT/工程或开始运行，会使旧结果失效。连续选择文件只采用最后一次；失败不会回退采用过期文件。运行期间输入参数保持锁定。

模板采用常规数值格式，不限制模拟量只能0/1；示例0/1让同一个模板可用于三种基本类型。预览与采样仍由原core.sample执行，算法、扫描周期和数值模型不变。
