# 多画布工程、信号匹配与统一扫描

产品 2.0.0 / 内核 0.35.0。算法仍为 62 种；这里增加的是模拟器的软件工程与调度功能，不是 Ovation 实机多任务行为的验证结论。

## 使用方法

顶部左侧集中放置“新建工程”“打开工程”“保存工程”。画布上方显示工程名称、画布页签及管理按钮。“＋画布”与“删除画布”并排；“导入 Control Sheet”与导入目标选择并排；可导入当前画布或导入新画布。旧工程 JSON 仍使用顶部“打开工程”。

页签从左到右就是扫描顺序，选中画布后用“优先级＋”向前移动、提前执行；“优先级－”向后移动、延后执行。双击页签就地重命名，Enter或失焦保存，Esc取消，空白名称不覆盖原名。运行时不允许重命名。工程名称仍在原位置编辑；命名、删除和组态修改支持撤销/重做。

顶部“保存工程”及Ctrl+S打开系统保存窗口，可选择文件夹和文件名；取消不保存，写入失败会明确提示。不支持系统保存选择器的浏览器改为下载，可在浏览器下载设置中启用“每次询问保存位置”。保存的是点击时的完整快照，包括所有画布、顺序、组态、原文来源、宏库、画纸、标题栏、示波器和统一扫描设置。重新打开后自动恢复同名信号关联。旧的单画布文件仍可打开；尚未启用多画布的工作流保留原有单画布格式。

导入 SVG 前，可在画布管理区选择“导入当前画布”或“导入新画布”。当前画布方式只替换这一张图，不替换其他画布；失败或取消保留原工程。多个主图仍由用户明确选择，宏文件继续作为定义保留，不凭文件排列猜测连接。

加入的画布统一使用当前工程的扫描周期和 UTC 起点。既有局部显式顺序、来源任务约束与问题审查保留；统一周期改变可能使原扫描确认过期，需要按扫描设置重新核对。

## 并列显示与尺寸

工程中有多张画布时，点击“并列显示”同时展示全部画布，各面板标题显示名称和原页签顺序。工程名称、原页签及优先级管理位置不变。点击面板或其中的模块激活完整编辑器，右侧属性和底部输入、波形、扫描记录跟随活动画布；每次只有一个活动编辑器，其余面板显示同一工程的实时值或回看帧。

拖动右下角调整各面板宽高；聚焦尺寸角标后用方向键微调，Shift加大步长，Esc取消当前拖动。“均分尺寸”按当前空间重新平分，空间不足可滚动；“单画布显示”返回原视图。布局仅保留在本次会话，不写入工程文件，也不改变扫描优先级或单独执行某张图。

新增、删除、排序、重命名、导入及撤销/重做后各面板同步更新；删除至一张画布时自动返回单画布视图。画布局部节点ID相同也按所在画布独立编辑，统一扫描和整拍回滚规则不变。

## 同名信号

- 不同画布中，模块名称去除首尾空白后完全相同的 OUTPUT 与 INPUT 自动关联；区分大小写，不做模糊匹配。
- 每个信号只允许一个 OUTPUT 来源，可以供其他画布的多个 INPUT 读取。多来源或类型不一致报错，不静默选择来源，不自动转换模拟量/数字量/LP。
- 同画布的同名端点不会生成隐式连接；现有物理连线保持。单画布兼容工作流保留旧同名观察点行为。
- 没有同名 OUTPUT 的 INPUT 继续使用自己的波形；同名但无 OUTPUT 的多个 INPUT 仍是独立输入。
- 已匹配 INPUT 显示来源画布及定位按钮。本地波形保留，但联动期间不采样；解除名称关联后继续使用原波形。被禁用的来源仍是来源，接收端及下游按依赖闭包暂停，不改用本地波形。
- OUTPUT 仍只有一个 IN1 物理输入端，其 OUT 是读数；跨画布关系不是额外的手工接线端。

“信号匹配”打开图形连接窗口，并暂停模拟，关闭后不自动恢复运行。窗口左边是 OUTPUT 输出来源，右边是 INPUT 接收端，均按画布分组。信号名称和画布名为主要标识，数字量显示开/关，类型显示数字量/模拟量/整字。

1. 点选左侧输出卡片；可连接的右侧输入亮起，同画布或类型不同的原因直接显示。
2. 点击右侧一个或多个接收输入，或从输出圆点拖线到输入卡片。虚线即时预览，但此时不修改工程。
3. 查看底部哪些 INPUT 将改为什么名称，再点“应用这条连接”或批量应用按钮。应用后自动建立同名关系并显示实线；整次编辑可撤销。

已有实线可以点选查看两端和本拍/上一拍读取关系，卡片上的“定位”跳转到所在画布，保留扫描历史。两栏可分别搜索名称/画布；“待连接”筛选仍保留已使用的输出来源，支持继续增加接收端。“有问题”集中查看重复来源和类型冲突。

“重新选择”、关闭或Esc取消待应用预览；拖线落空不生成连接。连接操作统一更名所选 INPUT，明确展示旧名→新名，原本地波形保留。不增加别名层、不自动改类型，也不把操作预览当作实际连接。

## 明确的软件扫描约定

整个工程共用扫描周期、逻辑 tick 和可选 UTC 起点。每拍依次执行画布，画布内部继续使用原拓扑顺序或已确认的人工顺序。

INPUT 执行时采样共享表中的当前值；OUTPUT 执行完成时更新本拍候选共享表。前面的画布向后面的画布传递本拍值，后面的画布向前面的画布传递上一拍值。扫描设置中的局部顺序同样适用：若 OUTPUT 尚未执行，不能提前发布其新值。

例如 A→B→C：本拍 A 的输出立即可供 B 使用，B 的结果立即可供 C 使用；A 若读取 C 的输出，则本拍取 C 上一拍的值。INPUT 快照记录实际读到的值，后序更新不回写已经执行过的 INPUT，也不重算前序画布。不迭代求稳态，不放开画布内部原有反馈限制。

t=0 仍是初态快照，不暗算组合逻辑。共享信号需要来源 OUTPUT 明确合法的 OUT 初态；匹配 INPUT 使用该初值，不能因为连接在后序画布就猜零。软件初态不等同控制器重启或现场运行状态。

所有画布成功后才统一提交状态、输出、共享信号和 tick。任一画布失败，前序画布已经准备的候选计算也全部放弃，保持最后成功快照，包括计时器、边沿记忆、队列和 LP 私有状态。错误同时标明画布与模块。

强制继续只覆盖发布值，正常私有计算不被改写。强制后的上游值可经 OUTPUT 传到其他画布。具名 LP 点仍分别属于各画布，不会仅因 packedPoint 同名而跨图共享。

禁用造成的依赖暂停会跨同名关系传播。“溯源恢复”旁的范围下拉默认“单页溯源”，只有一张画布时“跨页溯源”灰色不可用。

- 单页溯源：进入时只禁用当前画布，选择 OUTPUT 后只累积恢复该页上游；其他页的显式禁用状态不变。同一次工具模式中切换到未处理的画布，会先准备该页；返回已处理画布保留已恢复范围。如果外部来源仍禁用，本页对应输入仍显示依赖暂停。
- 跨页溯源：进入时禁用所有画布，从任意画布的 OUTPUT 沿实际接线与同名唯一来源关联逆向追踪，累积恢复全部相关页的上游，未选分支保持禁用。反馈关联用已访问集合去重，不无限追溯。
- 切换范围会退出工具并保留现有状态，再点击“溯源恢复”按新范围开始。Esc退出、撤销/重做及保存规则沿用原工具。待核连接和页内共享 LP 依赖仍按原规则处理，不猜测冲突来源。

## 保存、历史与复算

工程容器使用 documentType=`ovation-logic-engineering-project`、formatVersion=1，保存有序 canvases 数组；各画布保留局部 project、稳定画布 ID 和原局部节点/来源标识。原单画布 schemaVersion 4 仍专用于旧强制运行记录，没有被复用成工程格式。

完整记录使用扫描模型 `ordered-canvases-shared-signals-v1`，含整个工程、共享信号、全部画布的完整快照、实际执行顺序及当次临时强制。复算比较全部画布与共享值，不只比较当前可见画布；故障复算同时核对画布身份。

轨迹对照针对当前画布；加载完整工程记录作为参考时，按稳定画布 ID 投影后比较，并在报告中注明画布身份。切换画布后清除上一画布的参考和已计算对照，避免把同名局部节点误当成另一张图。

资源预算合计全部画布与共享表。达到工程记录上限后可以回看、导出和复位，不能为每张画布分别分配一个全量上限。

切换画布保留各自的输入草稿、临时强制、视图与临时标注；这些临时内容不写入普通工程文件。端点名称参与运算关联，更名清除旧运行轨迹；更改画布顺序、增删画布和逻辑修改同样清除轨迹。单纯切换、画布/工程标题与显示位置修改保留有效历史。

工程示例：`examples/multi-canvas.json`；手算逐拍输出：`examples/multi-canvas-reference.json`。已有 Node / 离线浏览器回归与精确记录复算仍属于软件证据，没有 Ovation 实机逐扫描对照。
