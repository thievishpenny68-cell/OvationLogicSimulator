# 同源主线、连接圆点与原图框

0.54.0 将同一模块、同一输出引脚的多个连接画成一棵连接树。公共部分只绘制一次，分线接入主线；三向及以上的分叉处显示实心圆点。不同源的信号即使当前值相同也各自独立，交叉处不加连接圆点。导入和手工连接使用同一套横竖布线。

每个源保留一个读数框，继续显示 SET / RESET、模拟量或打包字。连线与圆点随运行、回看更新。悬停某条分线仍显示该目标本拍实际读入值，包括顺序扫描时读取上一拍的情况。

点击公共主线或圆点，右侧列出全部目标。选择某个目标后可单独删除这条连接，也可直接点击独立分线。删除、撤销、移动与重新接线会重新布线，其余连接保持原逻辑身份。画法不改变工程的 edges、扫描顺序或计算规则。示例：[shared-signal-trunks.json](../../examples/shared-signal-trunks.json)。

## 导入图纸信息

导入程序读取主 SVG 中 `cb-classname="IncludeDocument"`、`cb-objectname="frame"` 的原图框，保留表格、静态文字和 DynamicText 字段。明文 `cb-source="cb-…"` 可引用根元素属性；0.54.1也按已知编码约束解析标准图框引用，从根属性读取实际值，未解明的引用保留导出正文。字段名解析不依赖数值相同这一条件。缺少正文且没有根属性值的字段显示“未提供”；多个同名图框会产生导入提示。

图框位于画纸右下角，随画纸大小移动，保持长宽比。包含项目、标题、版本、日期、Drawing Number、Drop、Task、Sheet、Engineer、Approved 及原有版权说明，实际字段以源文件为准。亮色和暗色模式均显示表格与文字。导入图纸采用 SVG 的有效 viewBox 或宽高作为初始画纸；新建空白工程仍默认 3600×2400。

图框提取结果以工程顶层 `titleBlock` 保存，完整来源仍在 `sources` 中。旧工程保留主 SVG 时可自动恢复显示，无需重新决定引脚映射。图框属于显示信息，修改它不改变计算指纹。安全预览器会过滤脚本、事件和外部资源；未提供原图框的工程不生成虚构图纸属性。

0.54.1恢复图框文本的原始字号（预览公共样式曾覆盖这些值），小字最小30画布单位；动态字段在所在表格行内居中。可点击尚未解析的橙色线段，在右侧查看原因并“删除此导入线段”，或按Delete。删除决定随工程保存，可撤销；原SVG和源连接证据保留。
