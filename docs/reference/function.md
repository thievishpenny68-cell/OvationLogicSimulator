# FUNCTION：分段线性函数

0.34.0新增；引擎0.24.0，数值模型`ref1100-2006-function-v1`。依据本地REF_1100（2006-05）§4.41 p170～173，正常全GOOD、无跟踪范围。原厂英文R3-1100 Rev3（10/02）§3-39也明确端点返回和重复X首遇Y规则，可作文字交叉核对：[原厂手册公开副本](https://powergenics.com/wp-content/uploads/2018/12/Ovation-Algorithms-Reference-Manual-R3_1100.pdf)。本地资料为实施基准，未取得Ovation运行采集。

## 参数和运算

IN1、OUT均为LA模拟量，上方输入、下方输出，采用p170矩形F(X)符号；两端均为圆形。TRIN/TOUT在原图位置灰显，当前不可连线；来源中的跟踪绑定仍作为未支持信息阻止运行。

先以GAIN、BIAS标度IN1，再按BPTS指定的2～12组X/Y断点查表。低于最小X取该端点Y，高于最大X取该端点Y，精确命中取对应Y，其余区间线性插值。GAIN不得为0。当前X阵列须非递减，不替用户排序。

重复X精确命中时按手册取阵列中首个Y，界外端点也采用该X的首个Y；相同Y的重复点可正常插值。重复X具有不同Y时，相邻区间的线性段如何衔接尚无唯一依据，当前明确停止该拍，保留原记录；不任选一个Y。其他不受该重复点影响的区间仍可运算。

**正常输出直接使用函数的Y值。** p170正文明确端点返回对应Y，TPSC/BTSC说明针对跟踪时的上下限匹配，本模块不套用INTERP的额外输出限幅。TPSC、BTSC与TRAT保存为跟踪配置，当前不参与正常OUT计算；BTSC不得大于TPSC。需要跟踪及限制状态字、反向函数、缓变或BAD输入处理的工程继续阻断。

新建预设按参数表保留：GAIN1、BIAS0、TPSC100、BTSC0、TRAT2.5、BPTS2，前两点(-100,-100)/(100,100)，其余槽0。导入不以这些预设补缺；活动断点必须有明确X/Y。未活动的3～12槽可以省略，若已声明却无效仍报错。t=0显示用户显式OUT初态，不执行函数。

输入标度和插值使用正常有限Float32分阶段运算，与相同Float32输入/参数的宽中间精度候选核对最终OUT；不一致、中间溢出、次正规结果均整拍拒绝。所有历史算法模型保持原值，新模型声明参与完整记录复算。

## 来源字段

|参数|LC字段|
|---|---|
|GAIN / BIAS / TPSC|T7 / T8 / T9|
|BTSC / TRAT / BPTS|U1 / U2 / X1|
|X1～X9 / X10～X12|R1～R9 / S1～S3|
|Y1～Y6 / Y7～Y12|S4～S9 / T1～T6|

命名SVG的X-1/Y-1等按别名关联到X1/Y1，并保留原文。p173的T2行名称印为Y-9，而描述为第8点Y；按相邻T1/Y7、T3/Y9及该行描述，将T2关联Y8。没有把真正命名的Y-9改成Y8。

## 可复核示例

打开`examples/function.json`，单步7次。七个函数覆盖默认两点、四点非单调Y、正负输入增益、12点表、不同Y重复点精确命中和同Y重复点插值；两台示波器观察输出。`function-reference.json`是独立字面期望：49项执行OUT及7项显式初态，共56项，按绝对/相对/时间容差0对照。

测试另外覆盖全部2～12断点数量、无效参数/类型/初态、TFT全部字段、重复点未明分支、精度分歧原子回滚、保存重跑与全部快照复算。这些证明声明范围内的手册规则与软件复现，不代替硬件时钟、质量或跟踪模式的验证。
