# 画布工具

0.56.0在顶部中间增加“画布工具”，0.57.0起提供“选择”“连线”和“删除工具”。删除模式的按钮为红色，画布指针变为十字，并显示操作提示。

## 溯源恢复

进入时禁用全图，随后仅点击OUTPUT观察点或其IN1端子，累加恢复所需上游。Esc退出后保留范围，重新进入再次全禁用；详见[溯源恢复](output-recovery.md)。

## 禁用与恢复

0.63.0增加“禁用”和“恢复”点击工具；与右侧“禁用此模块”设置相同，灰色模块和依赖它的下游不执行，连线保留。Esc退出，改动可撤销；详见[禁用规则](disabled-blocks.md)。

## 删除工具

点击“删除工具”启用，随后点击模块、逻辑连线、示波器、观察探针或未解析的导入线段即可删除。点击共享主线会删除该源的全部分线；点击独立分线只删除该目标连接。

在空白处按住左键拖框，松开后一次删除完整包含的对象。模块、示波器按完整外框判断，独立连线按整条路径判断。框正向或反向拖动均可。删除模块会同时清理它关联的连线、观察引用和量程配置；未解析连接留下拒绝记录，已删除模块的来源问题留下删除依据。原SVG和导入审计保留。

整批删除只产生一步历史，点击“撤销”或按Ctrl+Z可恢复。按Esc、再次点击删除工具或点击“选择”退出；删除模式中按住中键仍可平移。Esc可取消尚未松开的删除框。

启用删除工具会暂停正在运行的仿真；点击运行或单步会切回选择工具。删除逻辑对象按既有规则清除旧运行记录，单独删除示波器或探针保留运行轨迹。工具切换与空白框不修改工程。

## 连线工具

“连线”按连续点击方式绘制横竖折线，可从输出端或已有主线起笔，接到输入端完成，也可反向绘制。空白点击放置折点，Backspace撤回一个折点；Esc先取消当前草稿，再按一次退出工具。主线分支有实心连接圆点，详见[手绘连线工具](manual-wire-tool.md)。
