# 临时绘画工具

“绘画工具”与“画布工具”同排、隔开放置。0.65.0起工具栏只保留手写笔、橡皮擦、□方框、○圆形／椭圆和T文本按钮；点击各按钮打开设置小面板，样式与橡皮擦面板一致。

- **手写笔**：面板设置1、2、4、8、12、16屏幕像素粗细，以及红、橙、黄、绿、蓝、紫、黑、白八色；按住左键自由标注。
- **□方框**：面板设置颜色、粗细，按住左键拖动绘制空心矩形；支持从任意角反向拖动，按住Shift约束为正方形。
- **○圆形／椭圆**：面板设置颜色、粗细，拖动绘制空心椭圆，按住Shift约束为正圆。
- **T文本**：面板设置颜色、8～96像素字号。点击落字位置，在出现的文本框内输入；Enter换行，Ctrl+Enter或点击别处完成，Esc取消本次输入。采用固定的系统字体及浏览器内置回退字体，不提供字体选择、不加载网络字体。每次落字是独立的临时文本对象。
- **橡皮擦**：面板选择整笔擦除或局部擦除。整笔命中范围固定24像素，命中剩余笔迹可移除整条笔画、整个方框／椭圆或一段文本；点击空心形状内部或已擦空白不会误删。局部擦除可调4～120像素，默认24，只擦掉接触位置的像素。

四类标注各自保留当前页的颜色、粗细／字号，改设置只影响之后添加的内容。形状拖动时只有当前轮廓，不留下预览重影。局部擦除记录当时的大小，后续换大小、整笔删除或窗口重绘不会恢复旧缺口；后画的内容也不会被之前的擦除再次删除。

面板可用Esc、关闭按钮或点击面板外收起。再次点击手写笔或形状／文本按钮会打开设置；收起面板后再按Esc，或点击“选择”等其他工具，才退出绘画。文本输入框内的Esc先取消文字。绘图时全选、删除、撤销／重做快捷键不穿透到控制逻辑，文本输入框保留原生文字编辑。

标注是覆盖网页内容的屏幕图层，显示在功能块、连线、示波器之上；工具栏、设置面板和对话框继续可操作。退出绘画后，标注不拦截鼠标，可正常操作模块。标注不跟随图纸缩放和平移；窗口大小变化按原屏幕坐标重绘。运行中可标注，逐扫描刷新不覆盖或清除已有内容。

**不保存标注**：笔画、形状、文字及擦除记录仅存当前页面内存，工程JSON、运行记录和SVG导入审计不包含它们；关闭或刷新页面即丢弃。未使用绘画工具时不分配整屏位图；整笔命中只检查候选范围的临时位图，松开后缩回其像素缓冲。

0.65.1优化连续操作：整笔擦除及形状预览按显示帧合并处理，保留所有移动路径段；在松开、取消、切换工具前完成最后一段。空白像素缓存有2MiB上限，相关内容变化后更新。形状预览只还原变化区域，结束后释放临时底图缓冲；文字直接叠加，不重画旧标注。
