# GAINBIAS的TRAT与PROQ来源字段

0.32.0依据REF_1100（2006-05）§4.42 p174～177，支持TRAT和PROQ在已有无跟踪、全GOOD正常模式中的导入、保存及校验。GAINBIAS仍仅有LA输入IN1和LA输出OUT，OUT公式、Float32阶段运算及`ref1100-2006-gainbias-v1`数值模型不变。

|参数|LC字段|手册含义与新建预设|当前使用范围|
|---|---|---|---|
|TRAT|R5|跟踪缓变率（单位/秒），2.5|保存并校验正常有限Float32/零；无跟踪模式不参与OUT|
|PROQ|X1第1位|质量传播，默认ON；0=OFF，1=ON|只接受数字0/1；输入GOOD且OUT有效时，两选项输出质量均GOOD|

PROQ=ON时正常模式传播输入质量；OFF时OUT有效便设置GOOD。本软件没有开放非GOOD输入、无效数传播或跟踪状态字，不能以PROQ=OFF绕过现有质量范围。TRIN/TOUT没有可连端；已有跟踪绑定会保留并阻断，普通确认导入问题不能解除它。

旧工程缺TRAT/PROQ时，当前正常OUT公式可以继续执行，不推断完整控制器配置。新建节点采用手册预设；导入的源值优先且保留原文。字段已声明但无效或重复时，保留未解析记录，不能退化为“可省略参数”。同一规则也适用于其他已声明的可选参数。普通应用其他参数不会删除这些对象，必须显式填写有效值或重新核对来源。算法类型映射也会保留目标不支持的来源参数，即使该参数原先已被识别；不能借改类型清掉未处理的声明。原始导入审计不改写。

PROQ用ON/OFF选项表示，保存为数字位。非法代码、字符串`"1"`、布尔值等会显示未支持原值；修改其他参数不改变其类型。只有明确选择ON/OFF才采用数字1/0。SVG中的命名数值属性是源格式文本，按已知参数类型解析为数字，原始文本仍留在来源审计。

打开`examples/gainbias-source-options.json`扫描4次，用对应reference核对10项独立正常OUT期望。两个实例分别使用PROQ ON/OFF和不同TRAT，输出均为19、39、0、100；这只验证正常GOOD公式，不是非GOOD质量或跟踪的运行对照。

当前真实资料结构审计见开发审查记录：64逻辑对象、72图形连接、82条TFT记录分母及来源SHA保持。DSI宏GAINBIAS的TRAT1/R5与PROQ1/X1从不支持字段变为已解析；其他不透明字段、未识别类型、输入工况、初态、扫描配置和待核连线仍在，不代表整个宏已通过仿真验收。旧`source-field-audit.json`保留为历史审计。
