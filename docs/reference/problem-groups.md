# 检查与导入问题分类

0.60.0将当前问题分为两类，页签分别显示报错和警告数量。

- **报错（影响仿真执行）**：以运行前的实际内核检查及本次扫描失败为准，例如缺参数、缺输入、类型冲突、不支持模式、待处理连接或未确认扫描计划。先处理这些项目才能正常仿真。连接核对与修复工具也放在此区域。
- **警告（提醒，不影响仿真）**：只列未解决的非阻断提醒；即使还有警告，其他配置有效时仍可运行。

已解决项目不再列入当前问题或计数。查看、分类、展开资料不会改变工程、扫描规则或问题的处理记录；人工确认来源提示也不能消除真实的参数、类型和支持范围检查。

导入对象数量、逐字段历史统计、文件用途和默认值采用记录不作为当前报错。它们放在底部默认收起的“导入资料与历史快照”中，需要时可展开核对。“查看原SVG”和“导出逐对象核对清单”仍可直接使用。历史快照保持导入当时的状态，不会因当前问题已修复而改写。

报错使用红色，警告使用黄色；亮色与暗色模式均保留清晰的文字、边框和数量标记。此版本只调整问题展示，不降低运行检查或准确性要求。
