# 引脚、门图例、量程与黑夜模式

产品0.23.0，计算内核保持0.14.0；本批不修改算法、初态、时序和数值合同。

所有已知数字输入和输出端点为方形，模拟输入和输出端点为圆形；颜色、手册箭头、引脚名称和方向继续保留。既可从输出端拖线，也可依次点击输出和输入。信号类型由算法手册定义，改变显示不会放开混接限制。16位打包量用六边形，未确定类型用菱形并明确提示，不因当前值为0/1判断类型。ASSIGN允许当前范围的模拟/数字记录，确认类型后两端及手册箭头同步更新。示波器探针入口是多通道观察入口，保留空心样式。

AND/OR只绘制选中的输入，门体和排布随2～8路调整；AND保持手册D形，OR保持手册圆形。非连续选择如IN1/IN2/IN8保留真实编号。增减输入属于逻辑修改，会清除旧运行；取消输入时原连线保留并提示处理。参见gate-inputs.md。

## 示波器量程

1. 用输出端或内部状态探针接入信号。
2. 展开该示波器的“量程”，每路均可选择“自动”或“固定”。
3. 固定模式输入“下限”“上限”，点击该路“应用”。两数必须有限，下限小于上限，跨度须可表示；无效输入明确提示，旧量程继续生效。
4. 改回“自动”并应用，即按原规则缩放：数字0～1，模拟按窗口内有效样本范围，常量增加边距。

固定量程裁剪窗外波形并保留正确边界交点，完整当前读数仍显示；数据、内部状态、CSV/JSON、参考对照与复算均不被截断或修改。极窄量程也先裁剪再换算坐标，避免大数溢出造成无效图形。不同通道、不同示波器独立。量程随项目保存，支持撤销重做，不清除已有运行；草稿不会被逐扫描刷新覆盖。横轴仍固定0..W，满窗后FIFO左移，完整历史保留。

可选项目字段为`scopes[].ranges`，键沿用通道JSON字符串，值为`{"min":-5,"max":5}`；未配置的通道保持自动。旧项目无需迁移。缺失信号继续明确提示，不改绑到别的信号。

## 黑夜模式

顶部“黑夜模式”切换暗色，“浅色模式”切回；本机浏览器记住选择，默认浅色。偏好独立于项目和运行，关闭本机存储时仍可在当前页面切换。文字、表单、手册符号、探针、曲线、坐标、连线数值框和检查面板采用相应暗色样式；原SVG对照保留白底和原图颜色，便于核对。

SET保持红色，RESET在浅色下为黑色、黑夜下为清晰亮色；数字虚线、模拟实线继续区分。主题切换不复位、不改变时间和轨迹，也不增加工程撤销项。
