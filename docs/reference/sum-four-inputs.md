# SUM两路必接与两路可选

0.37.0/核心0.27.0：SUM模型升ref1100-2006-sum-exact-check-v3，增加对全部已接路完整乘加及求和的精确参考，比较最终限幅OUT。未接路/偏置不参与，其他参数不变；旧v1/v2完整记录须重跑，普通工程可打开重新运行。见exact-sum-check.md。下文v2为四路扩展时的历史版本。

0.31.0/核心0.22.0补齐REF_1100（2006-05）§4.112 p396～398中明确的四路正常运算。IN1/IN2必接，IN3/IN4可选，全部仅LA模拟量；OUT仅LA。手册原型的IN3/IN4已从灰色未支持端开放为模拟圆形可连端。TRIN/TOUT仍未支持，不能由本说明推断跟踪状态字、模式或输出已经实现。

每条已接输入先计算 `Ai = INi × INiG + INiB`，依IN1～IN4顺序求和，最后在BTSC～TPSC间限幅。没有接的IN3/IN4完全不参与，包括该路偏置；可只用IN4而不接IN3。IN1G不能初始化为0，沿用手册的限制。

|参数|LC字段|手册新建预设|
|---|---|---|
|IN3G|R8|1|
|IN3B|R9|0|
|IN4G|S1|1|
|IN4B|S2|0|

S2行的中文描述写作“Input 3 的偏置”，与参数名IN4B不一致。本实现按IN4B参数名和本节“四路分别带增益和偏置”的总述归入第四路；这是有依据的文档交叉解释，不是实机对照证据。

新建SUM包含这四个已知预设。旧两路工程未保存它们时可继续运行；一旦接入对应输入，就必须明确补齐该路增益/偏置，不在求值时擅自使用默认值。无效的已提供系数仍会报错。SVG命名属性、TFT的R8/R9/S1/S2按真实字段读取，来源原文保留。

数值与原两路规则一致：乘法和加法逐阶段Float32；全部累加后限幅，并与较高精度中间结果的候选比较。结果分歧或数值范围错误停止整拍，上一完整快照不变。当前只支持GOOD正常数/零和无跟踪；不会将未支持的跟踪输入当普通数相加。旧两路正常运算结果保留，SUM模型升级为`ref1100-2006-sum-four-input-v2`，旧v1完整运行记录需重跑，不将模型不同的记录冒充复算成功。

打开`examples/sum-four-inputs.json`扫描4次，可核对`sum-four-inputs-reference.json`的15项独立期望。包含完整四路、旧参数两路、跳过IN3只加IN4、每路独立增益/偏置、正负数及输出限幅；另有缺项、类型/字段归属、精度分歧、失败回滚和保存复算测试。依据是手册与软件回归，尚无Ovation实机采集。
