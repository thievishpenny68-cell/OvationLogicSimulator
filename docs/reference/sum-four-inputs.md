# SUM两路必接与两路可选

内核0.36.0采用`ref1100-2006-sum-optional-zero-v4`。已保存的普通工程可以重新运行，使用旧SUM模型的完整记录须重跑。精度核对见[精确求和说明](exact-sum-check.md)。

REF_1100（2006-05）§4.112 p396～399定义四路正常运算。IN1/IN2必接，IN3/IN4可选，全部仅LA模拟量；OUT仅LA。TRIN/TOUT仍未支持。

每路先计算 `Ai = INi × INiG + INiB`，依IN1～IN4顺序求和，最后在BTSC～TPSC间限幅。未接的IN3/IN4按§4.1 p24取0，该路偏置照常计入。IN1G须非零。

|参数|LC字段|手册新建预设|
|---|---|---|
|IN3G|R8|1|
|IN3B|R9|0|
|IN4G|S1|1|
|IN4B|S2|0|

S2行的中文描述写作“Input 3 的偏置”，与参数名IN4B不一致。本实现按IN4B参数名和本节“四路分别带增益和偏置”的总述归入第四路；这是有依据的文档交叉解释，不是实机对照证据。

新建SUM包含这四个预设。旧工程在对应输入未接且未保存参数时采用上表预设。对应输入一旦接入，就必须明确补齐该路增益和偏置。无效的已提供系数仍会报错。SVG命名属性、TFT的R8/R9/S1/S2按原字段读取，来源原文保留。

乘法和加法逐阶段Float32。全部累加后限幅，再与较高精度及精确算式的候选结果比较。结果分歧或数值范围错误时整拍回滚，保留上一完整快照。当前只支持GOOD正常数或零及无跟踪模式。

打开`examples/sum-four-inputs.json`扫描4次，可核对`sum-four-inputs-reference.json`的15项独立期望。包含完整四路、旧参数两路、跳过IN3只加IN4、每路独立增益/偏置、正负数及输出限幅；另有缺项、类型/字段归属、精度分歧、失败回滚和保存复算测试。依据是手册与软件回归，尚无Ovation实机采集。
