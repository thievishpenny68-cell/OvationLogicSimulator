# 四路示波器与输出总览

0.67.0更新观察界面，计算引擎仍为0.30.0。离线运行方式、仿真模型和完整逐扫描数据保持。

## 画布示波器

每台最多显示4路。点击输出端口后点“接入探针”，也可从输出端拖线到示波器入口。内部状态从右侧属性选探针。第5路会提示先移除一路或添加另一台示波器，已有通道和记录保留。信号列表仍可移除或替换通道。

四路使用不同颜色，卡片显示CH号、信号名称和值。数字量、LP字按阶梯显示，模拟量在实际采样点间连线；这不代表存在扫描间的真实采样。模拟读数显示6位有效数字，悬停数值可读完整记录值；LP读数为十六进制，导出保留原整数。

自动模式下，同图的模拟通道共用显示范围，便于比较幅值。各路可在“量程”中独立设置固定下限／上限；数字量的自动范围为0～1，LP字保持整数。点击卡片切换左侧纵轴，CH号及卡片边框指明当前轴；卡片下方列明各路显示范围。因此独立固定量程的波形不能仅按图上高度比较原始数值。

## 历史游标

先运行或单步，再点击“游标”。点击或拖动图中的虚线，所有通道读数切换到同一个真实扫描。选择最近的可见采样，恰好在两拍中间时选较早一拍；超出已采集部分时停在已有扫描上，不补数据、不插值。时间栏显示绝对秒数和扫描号。

图表获得焦点时可用左右键逐拍移动，Home/End移至可见采样首尾，Esc关闭游标。再次点击“游标”恢复当前读数。每台示波器和底部总览的游标互相独立，不改变全局回看位置、仿真状态、工程、撤销记录或完整轨迹；继续运行仍从最新已提交扫描推进。旧游标超出滚动窗口后会移到窗口内最近的实际采样。复位、新工程或载入另一份运行会清除旧游标。

## FIFO时间窗

选择1／5／10／30秒，画布示波器另保留“全程上限”。横坐标固定为0～时间窗长度：尚未填满时从左向右延伸，填满后整体向左滚动、在右侧加入新数据。时间栏单独显示实际绝对时间范围。添加、移除或更换信号不改变x轴刻度。

这只是显示窗口。窗口左边界附近保留必要的前一个样本用于连续绘图，裁剪到图内；历史游标只选择窗口内实际扫描。所有记录仍可导出和全局回看；回看时图表显示截至所选扫描的窗口，不把后续数据混入历史视图。

## 底部输出点状态总览

点击“输出点”展开按名称选择OUTPUT模块；可选一个或多个，不受单台示波器4路限制。选择器默认收起，彩色读数卡片常显，时间窗和游标位于同一行。点卡片切换纵轴，固定时间窗和FIFO行为与画布示波器一致。记录／对照信号仍单独选择。

## 旧工程及异常状态

旧工程保存超过4路的示波器时，引用不被删除，明确提示只显示前4路；在信号列表取消旧路后可切换剩余信号。新接入严格限制为4路。缺失信号保留原引用并提示，不自动改绑；坏采样显示断线，禁用／依赖暂停显示对应状态，不补0/FALSE。原有量程、位置、名称、大小和探针配置仍可保存，局部游标只保留当前页面。

示例：打开examples/oscilloscope-four-channels.json，运行约4秒后暂停，开启游标检查阶跃、温度、压力和流量四路；点击卡片查看不同固定量程。继续运行超过5秒可观察FIFO左移。
