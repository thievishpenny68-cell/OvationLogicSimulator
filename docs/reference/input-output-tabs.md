# INPUT设置与输出点状态总览

0.45.0按用户要求分离输入配置和输出观察。内核仍0.28.0，参数含义、输入采样、计算、记录及对照规则不变。

## 输入设置

0.49.0起，INPUT名称和信号类型在右侧属性栏设置，底部“输入设置”集中编辑变化规律、时间、值和波形预览。点击INPUT后进入该页；拖动时保持画布布局，普通点击结束后才展开。也可用右侧“编辑输入变化模式”入口，或在页内“选择INPUT输入源”切换。底部高度可通过画布提示条上沿拖动调整，左右侧栏可收起；见[工作区布局](workspace-panels.md)。

类型仍受已连接引脚约束：数字量使用TRUE/FALSE控件，不能选斜坡/线性；模拟量支持常量、阶跃、斜坡、保持及线性分段；LP整字使用0～65535及保持类模式。时刻以秒填写。类型切换按原规则重建输入规律并保留原配置来源记录；模式和值填写后点击“应用参数”采用。0.46.0起波形草稿跨源切换保留，并有即时图示及恢复入口，见input-wave-editor.md。

原缺失/未知输入、额外参数、来源对应及重新配置/撤销检查保留。运行期间参数锁定，可切换输入源查看；高级类型映射移到页尾折叠区。其他算法仍在右侧属性区配置。

## 输出点状态总览

原“信号总览”改名为“输出点状态总览”。只列出真正的OUTPUT观察终端，每项显示模块名称和信号类型（0.48.0起仅同名时附节点标识）；可勾选一个或多个。“全部输出点”恢复默认全选，“清空输出点”取消全部。

曲线图例显示模块名称（同名附标识）、类型和当前或回看时刻的读数；LP整字显示十六进制。类型未明确的OUTPUT列出但不能勾选，没有OUTPUT时提示添加终端。各级算法输出和内部状态继续可接独立示波器探针。

总览勾选只影响本页曲线，不改组态、轨迹、历史、CSV导出或已生成的对照报告。逐扫描表和对照仍通过“逐扫描 / 对照信号（含内部状态）”选择任意级信号，两个选择集合相互独立。

当前工程中的编辑、运行和回看保留总览勾选；新建、打开、导入或载入复算工程时重置为全部已明确类型的OUTPUT。需要保存的观察布局可用示波器及其探针随工程保存。

0.48.0命名与鼠标规则见module-names-and-selection.md。INPUT/OUTPUT使用独立“保存名称”，按名称选择；名称修改保留输入草稿和运行记录。
