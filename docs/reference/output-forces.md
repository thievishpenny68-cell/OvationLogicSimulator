# 临时强制输出

版本0.66.0 / 核心0.30.0。在画布选中一个功能块，右侧切到“强制输出”。勾选要固定的输出引脚，设置值后点“应用强制”。数字量只选0/FALSE或1/TRUE；模拟量填写具体有限数值，按现有Float32规则校验并舍入。可同时固定多个输出，其余输出正常计算。“取消本模块强制”恢复正常计算。

INPUT、OUTPUT不提供强制。LP/packed16整字输出不提供强制；例如FIRSTOUT只可强制MULT、NTRP、TRPD，UNPACK16可逐个强制数字位。引脚类型取自现有手册接口定义。改变块类型造成端口或类型失效时，必须重新应用或取消原强制，不自动转换值。

强制配置仅在当前页面内存中，普通工程保存不包含它；刷新、关闭页面或成功新建／打开／导入另一工程后清空。失败或取消打开不改变当前配置。逻辑撤销和重做不保存强制配置；删除模块也移除其配置。修改强制须先暂停，应用和取消都会清除旧运行及对照，从声明初态重新运行。复位不取消本页的强制。

这是模拟器的软件调试功能，采用`publish-override-private-state-v1`：模块照常运算，随后逐引脚覆盖对外输出。下游及连线、探针读到强制值；模块自己的递推、定时、记忆和初态仍使用未强制的计算值。例如强制ONDELAY.ACT不修改其计时状态，也不改变OUT的正常判定。真实外部反馈连线仍按扫描计划读入强制值；这与模块内部的递推不同。t0已发布强制输出，TRANSPORT INIT2据此初始化上游采样缓存，自身初态仍保留原始计算值。

强制不会绕过未实现算法／宏、缺少输入、参数、初态、扫描确认或数值精度阻断。禁用和依赖暂停的模块仍不运算、不发布值，其强制在模块恢复后才生效。展开宏前须先取消该宏的强制，以免强制错误地转移到内部共享驱动。

画布模块标“强制”，相应输出端子加橙色描边且保持原类型形状。0.66.1起，被强制引脚的整条信号线、共享主线、分支、连接圆点及数值框统一橙色，选中连线也保持橙色；接到该输出的示波器探针同步变橙，内部状态探针维持原色。数字量虚线、模拟量实线及SET/RESET／数值文本保留，取消强制后恢复正常配色。右侧逐引脚显示“计算”和“输出”，连线提示显示强制状态和原计算值；记录信号选项也标记强制。

导出运行记录仍保留本次实际使用的强制信息，保证结果可检查、可复算。仅这种运行记录使用版本4的工程证据副本，含原编辑版本、模型及参与范围内的强制值；`manifest.outputForcing`列出请求值和实际Float32值。快照`values`是发布值，`computedValues`仅为参与强制的模块保存完整未强制输出；其他模块不重复记录，记录容量计入这部分数据。完整复算同时检查强制声明和原计算值。主动载入复算结果会在当前页面恢复相同强制状态，并明确提示；随后普通“保存项目”仍不写入强制。

没有强制的旧工程和运行记录沿用原格式、扫描模型和算法模型。本功能不构成Ovation现场运行对照证据。
