# 工作区布局与紧凑输入设置

0.49.0根据网页批注调整工作区，内核仍为0.28.0。

## 底部区域

按住画布底部操作提示条的**上边沿**，上下拖动调整下方区域高度。向下拖可缩到仅保留页签；向上拖可重新展开。指针移到边沿会变成上下调整光标，边沿高亮。双击恢复当前页的默认高度。

手动高度在切换页签时保留；窗口缩小时会约束范围，为画布留出空间。拖动中按Escape、取消指针或窗口失焦会撤销这次调整。也可聚焦边沿，用方向键每次调整20像素，Home展开、End收起、Enter恢复默认。

## 左右侧栏

“控制块库”和“属性与内部状态”标题旁的箭头可独立收起侧栏。收起后保留42像素窄栏、面板名称和恢复箭头。再次点击箭头展开。搜索内容、属性表单和输入草稿保持，不销毁编辑器。

## INPUT属性与波形

选中INPUT后，在右侧属性栏设置模块名称、保存名称和信号类型。信号类型仍受已连接引脚限制；数字量使用TRUE/FALSE控件，模拟量及LP仍按原规则校验。高级类型映射也在右侧折叠项中。

底部“输入设置”专门编辑变化规律、时间、值、Excel导入及波形预览。输入源选择条随内容滚动；0.51.0使分段节点区扩展使用预览左侧的空白，多列从左到右排列并换行，普通字段最多480像素。预览列最多760像素并靠右。预览图常规高185像素，较矮窗口为160像素。默认输入面板最多460像素高，也可自行拖动调整。

新增“画纸设置”页签可调整位置、宽高、边界线型与显隐，并提示超出边界的对象；见[画纸与多列节点](paper-and-wave-grid.md)。

名称可独立保存，保留运行及草稿；时间和值仍需点击底部“应用参数”后用于仿真。更改信号类型会按原规则重建输入规律及清除旧运行。

布局状态仅供当前页面使用，不写入工程或运行记录。调整布局、折叠侧栏及切换页签不会推进仿真、清除历史或修改连线；算法、时序和误差标准保持不变。
