# RATEMON与RATECHANGE基础模式

产品1.3.0，内核0.32.0。依据拆分手册REF_1100 §4.84 p305–306、§4.82 p300–301。以下范围仅正常有限Float32/GOOD质量，没有Ovation实机逐扫描对照。

## RATEMON

输入IN1、可选择PRAT和NRAT均为LA；OUT为数字量，允许LD或LP位。PRAT/PDB/NRAT/NDB默认0.0，为非负绝对值。PRAT/NRAT连线时使用本拍输入，未连线时使用固定参数。PDB/NDB为固定整定常数。

令 `RATE=(IN1−OLDIN)/TS`。若 `RATE>PRAT` 或 `RATE<−NRAT` 则置位；否则，只有 `RATE<PRAT−PDB` 且 `RATE>−(NRAT−NDB)` 同时成立时复位；其他情况保持原OUT。所有等号均按手册严格比较处理。两个限值及死区均为0时，零变化率保持原状态。

手册本节仅将TS定义为采样/任务回路时间；模拟器按扫描周期的秒数代入，在参数页显示“单位/秒”。这是与RATECHANGE每秒单位及现有逻辑时钟一致的明确软件约定，不能代替特定Ovation平台的运行对照。

## RATECHANGE

IN1、可选择SMTH、OUT均LA。SMTH默认0.0，单位秒。本版只支持固定SMTH=0，或通过模拟引脚读到0；OUT为 `(IN1−上一拍IN1)/(扫描周期微秒/1000000)`，单位是输入单位/秒。正数表示上升，负数表示下降。

非零固定SMTH在运行前阻止；动态SMTH非零在对应扫描拒绝，保留最后完整快照。负SMTH涉及手册BAD质量分支，未实现。正SMTH的双重平滑也未开放，不把它当作简单差分运行。

## 起点、扫描和观察

两块均保存 `states.previousIN1`，可以通过状态探针观察。上一拍输入在本块成功计算后写入候选帧，只有所有块成功后整拍提交。复位恢复显式软件起点，首拍直接使用该旧输入；不会隐式把首拍变化率设为0。

手工新建预填OUT=0/FALSE、previousIN1=0以便编辑；用户可在属性栏修改。导入SVG保留空初态并提示补齐，手册组态默认值不会填充运行历史。t=0仅为软件快照，不代表控制器曾执行过一拍或重启状态。

强制OUT只改变发布值：回差记忆使用私有计算OUT，历史输入按正常扫描更新。禁用模块和依赖暂停沿用全局规则，保留连线。保存工程、运行记录和完整复算均携带明确起点及实际历史状态。

## 数值判据

沿用正常Float32及整拍回滚。变化率分步Float32与宽精度候选比较；另按量化后的输入和整数微秒计算精确有理数参考。RATECHANGE的最终Float32输出必须一致；RATEMON要求最终布尔决定一致，包含回差边界的精确比较。中间溢出、次正规数或最终决定分歧均停止本拍，不用放大容差掩盖。

432组独立有理数/100位Decimal向量覆盖不同周期、正负输入、回差与默认值：429组结果逐位/精确一致，3组必须报告精度分歧并回滚。它们验证软件合同，不代表实机平台等价。

## 示例

打开examples/rate-algorithms.json，250ms单步8次。RATECHANGE依次输出 `5,4,3,2,−5,−4,−3,−2`；RATEMON限值±4、死区1，依次输出 `TRUE,TRUE,TRUE,FALSE,TRUE,TRUE,TRUE,FALSE`。两块旧输入初值均0。examples/rate-algorithms-reference.json含45个数值/数字量观察和18个历史观察，共63项手算对照。

RATEMON图例按手册采用V/H及平行斜线；RATECHANGE采用手册竖向图例，IN1/SMTH在上、OUT在下。端子类型及模拟实心/数字空心箭头按原表和原图配置。
