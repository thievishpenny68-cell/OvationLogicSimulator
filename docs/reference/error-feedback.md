# 错误反馈

0.61.0在顶部“导入Control Sheet”和“使用说明”之间增加“错误反馈”。这是一个本地反馈文件生成器，使用者填写后把导出的ZIP作为邮件附件发送给开发者。

## 三步记录

1. **描述问题**：一句话概括、选择发生区域，说明涉及哪个模块/页面。按引导填写操作步骤、预期结果、实际现象和出现频率。自0.61.1起，所有描述字段均为选填，文字、图片或附件全部留空也可直接导出。
2. **添加图片**：点击“截图”并在浏览器窗口选择器中选择要截图的窗口/标签页；取得一帧后立即停止共享。也可用Win+Shift+S截取局部，回到反馈窗口按Ctrl+V粘贴，或选择现有PNG/JPG/WebP图片。支持6张、每张最多10MB，可填写图片说明或移除图片。文字反馈可以不带图片。
3. **导出反馈ZIP**：默认附上当前工程（包括原始导入资料），也可取消。已有运行记录时可选择附上完整运行记录；完整记录包含工程，供复算使用。导出后的提示说明如何通过邮件发送。

截图调用浏览器的[Screen Capture API](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getDisplayMedia)，须由使用者点击并在浏览器中选择捕获来源。取消、浏览器不支持或策略限制时保留草稿，提示改用截图后粘贴；不要求安装截图软件、扩展或启动后台服务。实际选择器由浏览器提供，页面不能代替使用者选中窗口。

## 现场与草稿

打开反馈会暂停仿真，保留组态、已记录数据、画布工具和临时标注。自动记录软件/内核版本、浏览器与视口、活动页签、画布视图、所选模块、实际运行诊断、当前扫描快照及最多20项页面异常。工程附件保存已应用参数，未应用的界面草稿仍可通过图片和描述说明。

关闭反馈窗口保留本页草稿，再次打开会暂停当前仿真，但仍使用原先记录的现场与对应运行清单。点击“更新现场记录”才替换现场；文字和图片保留。点击“清空重填”开始新反馈。刷新或关闭网页后草稿清空。反馈不会自动恢复运行，使用者可在关闭后自行继续。

## 文件格式

ZIP采用UTF-8文件名、标准无压缩ZIP条目和CRC32，便于常见解压工具与大模型读取。每份文件放在一个带UTC时间标识的目录中：

| 文件 | 内容 |
| --- | --- |
| issue.md | 供人和大模型首先阅读的说明，按相对路径引用图片与附件 |
| issue.json | schemaVersion=1、反馈类型、时间、结构化描述、现场记录及图片清单 |
| images/01.png等 | 独立PNG图片，JSON中列出路径、尺寸、字节数、来源、时间和说明 |
| project.json | 可选，模拟器可直接打开的工程，包含所选原始导入资料 |
| run-record.json | 可选，完整运行清单与扫描轨迹，可用模拟器复算 |

图片均经浏览器解码并转成PNG，不把图片塞成难读的大段Base64文字。开发者或大模型解压后先读issue.md与issue.json，再查看列出的图片，按需要打开工程或复算运行记录。报告属于使用者的故障线索，不代表故障已确认、原因已定位或Ovation运行结果已获验证。
