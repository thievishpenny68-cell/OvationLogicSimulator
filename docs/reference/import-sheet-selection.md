# 选择导入主图

一次可以选择Control Sheet及其MCR、TFT、XML等配套文件。0.15.0起不按文件排列顺序猜测主图：

- 只有一张ControlFunction时，以它为主图；ControlMacro文件保留为可展开的宏定义。
- 没有ControlFunction、只有一张ControlMacro时，以该宏为主图。
- 多张ControlFunction，或没有ControlFunction但有多个宏时，先显示文件名、类型和标题。请选择要编辑的主图，再点击“导入所选主图”。也可明确选择列表中的宏作为主图。
- 取消或按Esc返回原图，不改变工程、运行记录或撤销历史。选择尚未采用时，后台图纸不能被Delete或撤销快捷键修改。

所选主图的对象进入可编辑画布，宏定义仍保留在宏库中。没有采用的其他ControlFunction不会自动合并，也不建立跨图连接；问题清单会列出其文件名，原文仍随工程保存，可另行导入。找到主图后，未知块、缺参、辅助文件错误继续进入原有诊断和人工修复流程，不代表已经可以运行。

文件名重复时不能唯一识别目标。请给文件及其配套来源使用一致、互不混淆的名称后重新选择；界面禁用重名目标。唯一主图带有重名宏时仍可导入主图，重名宏不生成空定义，保留原文并报告来源冲突。

运行中请先暂停，再导入；导入会改变计算配置并清除之前的运行轨迹，取消选择则保留原轨迹。正常暂停后仍可通过一次撤销恢复导入前的工程，撤销不恢复旧计算轨迹。

采用范围记录在导入快照`importAudit.sheetSelection`，包含目标、选择方式及每份已识别图纸的用途：主图、宏定义或未导入。它说明本次导入用了哪些图纸，不确认算法规则、参数、初态、扫描或连接。旧工程没有此记录时保持原状，重新导入才能取得新记录。

供工具调用的`importFiles(files, Parser, {target})`同样要求指定名称唯一存在；不存在或重名时返回诊断，不回退到其他文件。`selectionRequired`及`targets`供界面选择使用，`targetFound`只表示已选定主图，不是准确性结论。
