## 接口与显式初态

- IN1是数字输入；OUT是数字输出；ACT是模拟输出，可同扫描驱动下级模拟块。
- BASE固定，以秒/计时单位计，正常最小0.1秒。**仅ONESHOT允许BASE=0，按1秒解释**（p259）。缺失配置仍报缺，不因为文件导出不完整而猜参数。
- TARG固定，单位为计时单位数。动态外接TARG/ACT、在线整定、控制器冷/热重启和冗余切换尚不支持。
- 用户初态为OUT、ACT和previousIN1（上一拍输入，用于沿检测）；全部必须明确。新建显示FALSE/0/FALSE，导入不填缺失初态。
- t=0只显示初态，不执行算法。ONESHOT初态OUT=TRUE表示脉冲已在计时；OFFDELAY初态OUT=TRUE且previousIN1=FALSE表示延时已在计时。此时从ACT建立t0计时锚点，首执行扫描推进一个周期。其他初态等待相应沿事件。这是用户状态恢复约定，不是控制器重启规则。
- 输入已为TRUE而previousIN1也为TRUE时不会人为补一个上升沿。若希望首扫描触发，应显式选择previousIN1=FALSE。

## 公共数值规则

计时使用整数逻辑微秒段；生成ACT时依次将秒数、除以有效BASE、加ACT锚点的结果转为Float32，和ONDELAY相同。跨过目标后保留实际累计值，不夹紧到TARG。GOOD质量、正常有限数/零；不支持数值会明确报错，整拍原子提交。

负TARG或负ACT优先：OUT FALSE；ACT、沿记忆和内部计时全部保持，不再处理新沿或其他复位。NaN/无穷/次正规输入不模拟为负值分支，而是在当前正常数值模式中拒绝。

## OFFDELAY

执行顺序：

1. 正常扫描先识别新上升沿。出现时将ACT清零、取消旧计时段，并依据新ACT与TARG决定输出；正目标OUT TRUE。
2. ACT≥TARG时OUT FALSE并停止计时。**TARG=0时，上升沿清零后的0仍达到目标，因此所有执行扫描OUT均为FALSE。** 这是按p254“如果ACT>=TARG，则停止OUT输出”选择并明示的优先级；没有将零目标当作直通。
3. 未到目标且IN1维持TRUE时，保持此前OUT，不累计；只有新的上升沿启用输出并清零ACT。OUT初值FALSE且previousIN1=TRUE时，已有高电平不会覆盖FALSE，也不抹掉明确提供的非零ACT初值。
4. 已启用OUT的下降沿建立计时段，普通目标该拍ACT保持，随后每拍计入一个周期。OUT尚未启用时的下降沿不产生延伸输出。若正目标名义时间不大于一个周期，下降拍计入一个周期，可当拍到期（p254的小目标允许分支）。
5. 低电平期间继续当前段，累计后ACT≥TARG时当拍OUT FALSE，之后保持ACT，直到下次上升沿清零重触发。没有正在计时的段、也没有下降沿时保持停用，不凭空开始延时。

新上升沿先于旧到期判定，因此重触发不会产生旧脉冲到期造成的一拍FALSE间隙。零目标重叠分支、下降拍首增量和事件同拍顺序是公开的扫描合同，未声称已采集硬件同拍行为。

## ONESHOT

1. 正常扫描的新上升沿清零ACT并重新建立计时段，正目标立即OUT TRUE；该拍ACT=0，随后才按完整周期推进。
2. 新上升沿在旧到期判定之前处理，即使与旧到期同拍也重新给出完整脉冲。
3. 输入下降不终止计时，持续高电平不重复触发。
4. ACT≥TARG时停止OUT并保持ACT。TARG=0在任何执行扫描都不出脉冲；新上升沿仍执行ACT清零。
5. 正的小目标也至少保留一个执行扫描的TRUE，不套用OFFDELAY下降拍到期分支。手册规定上升沿启用输出，离散到期在后续扫描判断。
6. 没有上升沿且初态不表示计时中的脉冲，不因ACT<TARG就产生输出。

## 期望轨迹与误差判据

示例周期0.1秒、BASE1、TARG0.25，输入0.2秒上升、0.4秒下降：

|秒|OFFDELAY ACT / OUT|ONESHOT ACT / OUT|
|---:|---|---|
|0.1|0 / FALSE|0 / FALSE|
|0.2|0 / TRUE|0 / TRUE|
|0.3|0 / TRUE|0.1 / TRUE|
|0.4|0 / TRUE|0.2 / TRUE|
|0.5|0.1 / TRUE|0.3 / FALSE|
|0.6|0.2 / TRUE|0.3 / FALSE|
|0.7|0.3 / FALSE|0.3 / FALSE|

表为本扫描合同的独立期望推导，不是现场采集。ACT按明确Float32期望回归，OUT逐拍精确比较；外部轨迹仍需显式abs/rel/time容差。小目标、采样相位、浮点量级会影响名义连续时长，不用额外epsilon静默改变比较结果。
