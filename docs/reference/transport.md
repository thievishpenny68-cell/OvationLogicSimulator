# TRANSPORT 模拟量传输延迟

依据本地REF_1100（2006-05）§4.120 p415～416。IN1和OUT均仅允许LA模拟量；使用手册矩形内波形与竖线符号，上方输入、下方输出，两端为模拟圆形。源字段TSAM=T9、NSAM=G0、INIT=X1。

TSAM以秒表示，低于扫描周期时使用扫描周期。NSAM为整数，实际样本数限幅至1～25，保留原始参数而不改写来源。有效传输延迟为有效采样时间乘以实际样本数。每次采样先输出原最早样本，样本前移，再录入本次执行时的IN1；新样本在NSAM个采样周期后输出。其他扫描保持上次输出。内存固定25个槽，每个值都是正常有限Float32或0。

五种INIT用于延迟线初始化：

|INIT|本软件新运行起点的样本|
|---|---|
|0、1|0，按手册首次加入算法规则|
|2|连接驱动的t0值|
|3|明确的OUT软件初值|
|4|0|

软件t0是扫描前观察值，所有节点值建立后再初始化延迟线，避免取值受节点数组顺序影响。这里不提前执行上游：INPUT使用t0工况值，其他节点使用各自明确的扫描前输出。t0 OUT仍是工程保存的初值；首次执行将初始化后的最早样本作为OUT，不提前移位。首次采样位于t0加一个有效采样周期，相位固定，之后周期重复。示例 `examples/transport.json` 每0.1秒扫描、每0.2秒采样、NSAM=2；运行8次可用独立字面参考核对45项输出与18项内部槽/相位，共63项。

可通过状态探针观察S01～S25、phase及firstPass。S01是尚未输出的最早样本，超出实际NSAM的槽始终为0；phase是距上次采样的扫描数，firstPass标记软件首次执行。完整记录包含全部状态，复算逐项检查，失败扫描不提交新样本或相位。

支持范围：GOOD质量、正常有限Float32；TSAM按Float32解释。当前只支持TSAM不大于扫描周期，或Float32意义上等于扫描周期整数倍；倍数须可被安全整数表示。非对齐采样周期的跨扫描处理尚未核实，明确阻止运行，不猜向上/向下取整。改变扫描周期可能使原配置不再对齐。

本软件“复位”重新建立相同t0工况和延迟线，用于可复现试验，不模拟控制器热重启或故障切换。手册关于INIT0/1热重启保留旧样本的路径不在当前范围，也不提供运行中改参数或恢复任意历史缓冲区。无效数/质量传播受既有GOOD范围限制，不能宣称已复现BAD传播。手册规则、软件相位约定及回归测试不构成Ovation实机采集证据。
