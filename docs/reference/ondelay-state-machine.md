# ONDELAY 扫描模型 v3

2026-11-03，产品0.17.0、核心0.10.0，模型标识`ref1100-2006-scan-v3`。修正把每次恢复都当作首次启动、导致单拍TRUE脉冲不能累计的实现错误；保留精度候选核对，见`precision-validation.md`。

依据本地REF_1100（2006-05）§4.68 p256～257及p257时序图；跨目标不夹紧采用用户已给出的人工手册解读。首次启动当拍ACT保持，与已确认连续工况一致；暂停与恢复不再抹掉每段首拍。尚无Ovation运行采集，不把软件回归称为现场采集。

## 接口、初态与支持范围

- IN1、ENBL：固定数字输入。OUT：数字输出；ACT：模拟输出，可同扫描连接下级模拟块。
- BASE：秒/计时单位，最小0.1，固定参数；TARG：目标计时单位数，固定参数，允许小数。BASE不是项目扫描周期。
- OUT、ACT为显式用户初态。新建块显示FALSE/0；导入块不补缺失初态，需配置。t=0是初始快照，不执行逻辑，内部计时为停止态；软件复位恢复这些值。不是控制器冷/热重启或切换。
- 当前限定单任务无环图、GOOD质量、正常有限Float32/零。动态外接TARG/ACT、在线整定、控制器重启/切换、NaN/无穷/次正规处理不在当前执行范围；不支持的源引用、字段或参数仍报错。有限负TARG/ACT按手册的停止分支处理。

## 按以下顺序执行

|条件|ACT / OUT|依据|
|---|---|---|
|TARG或ACT为负|ACT和内部计时保持，OUT FALSE；不执行ENBL复位等其他操作|p256“但不执行任何其他操作”|
|ENBL FALSE|ACT清零，OUT FALSE，清除内部计时|p256明确规则|
|ENBL TRUE且TARG=0|OUT沿用IN1；ACT保持，不累计|p256零目标特例；保持ACT遵循“未要求修改则保留”的扫描契约|
|ENBL TRUE、TARG>0、ACT≥TARG|ACT保持，OUT TRUE；IN1变化不起作用|p256停止条件；最终值可跨过目标，采用人工解读，不夹紧|
|ENBL TRUE、ACT<TARG、IN1 FALSE|ACT及累计时间保持，OUT FALSE，暂停但不清除started|p256保持规则；p257时序图|
|复位后首次满足累计条件|started置TRUE，以当前ACT建立锚点，普通目标当拍不累计|首拍ACT0与人工工况一致|
|暂停后恢复，或持续满足累计条件|有效累计时间增加一个扫描周期，生成ACT后与TARG比较；本拍达到即可OUT TRUE|p256恢复累计；首次启动与恢复采用不同分支|

**小目标首拍分支：** 手册允许正目标时长不大于一个扫描周期时在首扫描输出TRUE。本模型对该分支在首次有效扫描计入一个完整周期，ACT可跨过TARG，OUT当拍TRUE。该首拍ACT及扫描相位处理是明示的模型约定，不能当作已采集的硬件读数。

暂停扫描冻结ACT和有效累计时间；恢复当拍立即计入一个周期，不把暂停时长算入。累计始终从原锚点换算，不在每次恢复时重新锚定已舍入ACT。达到目标后停止计时，保留ACT及累计记录。ENBL FALSE清除started、锚点和累计时间；下一次才重新执行首次启动。更改组态会清除旧运行，不模拟在线修改TARG。

**短脉冲回归：** 周期0.1秒、BASE1、TARG0.35、初始ACT0、ENBL始终TRUE；IN1在0.2/0.4/0.6/0.8/1.0秒为TRUE，其余拍FALSE。对应TRUE拍ACT依次为0、0.1、0.2、0.3、0.4；1.0秒OUT置TRUE，之后保持。`examples/ondelay-retentive-pulses.json`可直接打开，10次单步达到目标，第11拍IN1下降后OUT仍TRUE。旧v2的全程ACT0是被修正的实现错误，不再作为当前使用限制保留。

## 数值与可复现计时

elapsedUs为有效累计的整数逻辑微秒，不读墙钟、不按界面刷新累计。ACT生成顺序为：

1. 将本段elapsedUs/1e6转换为Float32秒数。
2. 除以已转换的Float32 BASE，结果转换为Float32计时单位数。
3. 加上本段Float32 ACT锚点，转换为Float32 ACT，再与Float32 TARG比较。

不循环累加浮点Δ，避免非二进制扫描周期的累计漂移。内部timing、started、elapsedUs、anchorACT可选择观察；它们是软件运行状态，不是额外Ovation引脚或可直接配置的初态。秒数、除法或加法产生不支持数值时整拍失败，不提交时间/状态。新运行记录保存v3；旧v2 ONDELAY完整记录不能用新规则复算或载入，保留原文件供检查。普通工程重新打开后按当前修正规则运行。

同一模型、初态、输入及周期的OUT逐拍精确一致；ACT回归按明确Float32期望比较。外部对照使用显式abs/rel/time容差。十进制0.4在ACT中为0.4000000059604645；不能仅凭文本简写认为是不同值或要求双精度十进制逐位相等。大数值的Float32分辨率与扫描量化共同限制时间分辨率，不承诺所有量级的连续名义延迟都只有一个扫描的误差。

原始资料输入保持只读。用户已要求直接按手册推进，不再重复询问这些规则。后续取得真实参考时，用相同配置对照并记录差异，必要时新增明确版本的模型，不静默改写既有运行的含义。

版本核对（2026-11-01）：本地2006 p257明确ENBL为必选，当前仍要求显式连接；2016 OW360_R1100 §5.74另有ENBL可省略的说明，不能混入本profile自动补线。时序图没有扫描网格或ACT离散轨迹，小目标允许当拍响应不等于规定全部内部增量。此次审查保留上述模型约定，没有从图形长度反推扫描数。
