# QAVERAGE 多路未加权平均

0.37.0/核心0.27.0：QAVERAGE模型升ref1100-2006-qaverage-v2，除原分阶段/宽候选外，增加完整输入精确求和并在除实际数量后才舍入的参考。分歧只拒绝，不选择参考输出；旧v1完整记录需重跑，普通工程配置保持。见exact-sum-check.md。

依据本地REF_1100（2006-05）§4.80 p297。IN1～IN8均为可选LA模拟输入，OUT仅LA；没有NMIN参数。必须连接至少一路，按实际连接的输入数求平均，未接引脚不视为0。同一源接入多个输入时，每个连接端分别计入平均值。模块采用手册八输入母线、ΣQ/N及对角线符号，输入和输出都为模拟圆形端点。

当前实现使用模拟器已有范围：所有已接输入均为GOOD、正常有限Float32（或0），由软件控制图每扫描更新。恒定输入每扫描仍有明确的软件值更新，不因数值未变化而剔除。没有接入其他状态或外部更新丢失的隐式推断。

手册还定义了BAD或未更新输入的剔除、最差质量传播、全部BAD时保持旧值等行为。本软件尚未实现这些质量路径，非GOOD工况由全局校验明确拒绝，不能把BAD当作0或悄悄放入平均。FAIR、未更新和质量传播的现场行为不能从本版结果推断。

数值合同与既有算术块一致：输入按IN1～IN8编号顺序累加，各次加法和最终除法采用Float32；与较高精度累加后最终转Float32的结果不同则停止整拍。中间累加溢出或最终结果落入次正规范围也明确停止，即使另一求平均公式可能得到有限数也不静默切换计算方法。尚未通过实机对照确定控制器中间累加精度。软件t0为明确的扫描前输出，首扫描才求均值。

打开 `examples/qaverage.json`，三路输入接IN2/IN5/IN8，另一个实例只接IN8。运行4次，以 `qaverage-reference.json` 核对10项独立字面期望：1/2/3均值2，4/5/6均值5，7/8/9均值8，−2/−4/−6均值−4。测试另覆盖全部255种非空端口集合、常见小数、精度分歧、数值范围、类型/质量拒绝、原子回滚和完整复算；证据为手册与软件回归，不是Ovation运行采集。
