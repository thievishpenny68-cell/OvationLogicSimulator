# 赋值、插值与整数查表（0.22.0）

本版补充三种基础模块，当前共40种可执行原厂算法；所有模块按手册功能符号显示，PACK16/UNPACK16继续只支持接口组态。以本地REF_1100（2006-05）为准，输入类型和输出类型随所选记录类型固定，不能通过接线把数字量当作模拟量。

## ASSIGN — §4.13 p44

同类型传递IN1至OUT。当前支持模拟量→模拟量、数字量→数字量，两端类型同时由“信号类型”选择；数字输入只有开关量测试方式。0.26.0起同时支持严格LP整字到LP整字传递，共享目的点须明确身份/初态/顺序（见packed-words.md）；不支持质量传播；正常有限Float32/GOOD范围继承全局规则。

导入时不会按ASSIGN名称猜类型；可沿已明确且确认的连接约束确定同一记录类型，冲突保留并提示。仿真输出按工程节点/针脚身份区分，未实现控制器实际点名分配与默认点规则。

符号按原页开口箭形轮廓绘制，与普通矩形块区分。

## INTERP — §4.52 p197～200

- XIN和Y1～Y10均为模拟输入，YOUT模拟输出，VALID数字输出。NUMR选择2～10个表节点，X1～XNUMR为固定模拟参数，对应数量的Y输入必须明确接线。
- TYPE明确为LINEAR；不推断来源中的未知数字编码。X1～XNUMR须给出；未采用的X参数可以缺省，不参与计算。新建时提供可修改的工作表，导入缺参仍须补齐。
- XIN等于表节点时采用对应Y，节点之间按手册公式`Yn + (Yn+1-Yn) × ((XIN-Xn)/(Xn+1-Xn))`插值，再应用BTSC/TPSC限幅。
- 闭区间X1～XNUMR内VALID=TRUE；低于第一节点输出第一Y，高于最后节点输出最后Y，VALID=FALSE。
- 按p198检测到X表未严格递增时采用最后Y、VALID=FALSE；不自动重排或去重。表格异常仍可观察，不生成凭空排序后的结果。

p198中文正文的下界句写作“XIN < X10”，与p197相邻节点插值定义不一致。本实现依据p197公式和p198相邻区间插值图，将下界应用于第一节点；随包边界参考明确覆盖。区间端点的VALID按“介于表内”作闭区间处理并公开，不声称取得实机逐扫描读数。

原页功能图的XIN/Y1～Y10在上方，YOUT在下方，VALID在右方；针脚文字按原图竖排。未选Y输入以灰色提示且不可接线。画布块值显示真正的YOUT，不增造OUT别名。

## TRANSLATOR — §4.119 p411～414

IN1模拟输入先按p411的向下取整规则取得整数索引；1～50分别选择I01～I50。已选但未配置的槽按手册为0。索引小于1或大于50保持此前OUT，所以必须明确OUT初态；保持状态随保存和完整复算记录保留。

当前槽值仅支持-32768～32767的整数。p411给出最大+32767，REF_1140 §1.5 p5定义16位有符号整数范围；REF_1140 §5.6.11 p129说明现代算法G等字段为32位整数，本版不据字段宽度扩大TRANSLATOR原章的声明范围。

p412～414部分字段名重复，与p411符号旁表格存在差异。本版接受明确的SVG属性`cb-alg-i01`～`cb-alg-i50`及人工槽配置；仅凭TFT原字段代码不自动猜槽。未解释的TFT字段保留并提示，可在现有参数对应界面补充依据。未声明的槽返回0是手册规则；未解析的来源数据仍不能被当作“未配置”静默忽略。

## 数值与试用

所有模拟量限正常有限Float32或0、GOOD质量；无效数/非GOOD质量、打包点模式不纳入本版。插值采用分阶段Float32运算，同时核对较高精度候选的最终限幅输出；有效YOUT不同则整拍停止并回滚。初态、复位、记录和重新运行采用同一数值转换，布尔精确比较，不加隐含epsilon。

打开`examples/lookup-blocks.json`，单步10次。示波器观察模拟/数字ASSIGN、INTERP的YOUT/VALID，以及TRANSLATOR输出；包含上下界、插值、地址截断和越界保持。配套`lookup-blocks-reference.json`由手册公式独立填写50个输出和5个软件初态，可零容差核对；不是模拟器导出或Ovation运行采集。

原定时块模型、FIFO横轴和其他37种算法不改变。设备/顺控、复杂质量与跟踪、PID、过程滤波/预测、蒸汽燃气特性等复杂模块继续暂缓。
