# 连线状态与数值

0.11.0新增。逻辑连线小框显示当前选中扫描的**源端输出**，运行、单步和历史回看时同步更新。

- 数字量：虚线；TRUE为红色SET，FALSE为黑色RESET。
- 模拟量：实线；显示6位有效数字，大于等于1e6或小于1e-3的非零显示值使用科学计数。负零显示为-0。
- 未运行、无有效记录或类型未定时显示灰色“—”，不会当作RESET或零值。
- 工具栏“连线数值”可显示/隐藏小框，连线类型和颜色仍保留。此开关为当前界面偏好，不改变工程或记录。

小框四舍五入只影响显示。悬停连线或小框可查看完整记录值；JSON/CSV、下级块和示波器仍使用原仿真值。点击小框也可选中连线，选中或悬停模拟线保持实线。

顺序回读时，源端本拍末值可能不同于目标本拍实际读入。悬停会另列目标读入值，并标出“顺序回读上一拍”；初始快照明确标记尚未扫描。失败扫描不会显示未提交的新值，复位后回到未运行显示。

示例`examples/wire-values.json`包含开关量及取反、模拟斜坡及绝对值，可观察SET/RESET颜色变化和模拟值。显示开关、回看和移动节点保留历史；改变真实逻辑仍按既有规则建立新运行。

示波器观察探针同样按类型显示线型和值框，包括内部状态探针；模拟探针保留对应通道配色，数字探针按SET/RESET着色。观察探针只取被观察源值，不作为目标控制块输入计算。显示开关同时控制逻辑线和探针线的小框。

0.54.0起同一输出的多个目标共用一棵主线/分线，每个源仅一个数值框，分叉处加实心圆点。点击主线后在右侧选择具体目标，可单独删除分线；不同源相交不视为连接。详见[同源主线与原图框](shared-signal-trunks-and-title-block.md)。
