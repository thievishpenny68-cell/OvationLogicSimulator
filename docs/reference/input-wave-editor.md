# INPUT波形编辑与预览

0.46.0增加INPUT表格编辑、示例和实时预览。核心仍0.28.0，五种输入模式及Float32/LA、LD、LP类型规则不变；INPUT是软件信号发生器。

0.49.0将名称和信号类型放回右侧属性栏，底部表单改为紧凑布局并限制字段宽度；可拖动上沿调整面板高度。详见[工作区布局](workspace-panels.md)。

0.50.0使输入源条与内容同滚动，宽屏预览靠右使用可用空白，左侧字段保持紧凑。INPUT/OUTPUT的新外形和手动方向选择见[输入输出方向](io-orientation.md)。

0.51.0让分段节点区占用预览左侧的可用宽度，多列从左到右再换行，较窄窗口自动减少列数。普通常量/阶跃/斜坡字段保持紧凑；详见[画纸与多列节点](paper-and-wave-grid.md)。

## 编辑

在“输入设置”选择输入源。模式按钮和“填入示例”会填入可修改草稿，明确标记“尚未应用”。常量、阶跃、斜坡按字段填写；所有分段模式用时刻/值表格增加或删除节点，不再要求模拟量手写逗号文本。数字量只给TRUE/FALSE，LP字限定0～65535（可输入十六进制），斜坡与线性仅模拟量可用。时刻固定秒。

节点必须按表格顺序严格递增，不自动排序或合并重复时刻。首节点前使用首值，末节点后保持末值；示例不会替用户核实来源含义。已载入未知/损坏波形仍显示原文，必须明确“重新配置输入规律”，保留旧配置与撤销记录。

## 即时波形

编辑控件时立即重画，不需要先运行。可以修改预览终点，移动指针查看时刻/值及最近扫描采样。线表示输入规律示意，圆点按当前扫描周期用内核sample计算。例：100ms周期、0.35秒阶跃，线在0.35秒变化，采样在0.3秒保持旧值、0.4秒才取新值。预览是输入源的规律；其他块t=0仍保留各自初值，不等于已经执行一遍算法。

通常最多201个采样点；长窗口明确显示抽取步长/总样本数，并保留末扫描。分段线保留显式事件时刻。无效/未填值会清除旧曲线并就地报错，不显示一条看似仍有效的旧图。预览不推进仿真、不写入或修改运行记录；极长窗口/无效扫描周期可使预览不可用，不改变原输入配置。

## 草稿与运行

切换INPUT保留波形草稿；“恢复已应用设置”丢弃当前源草稿并保留旧运行。点击“应用参数”通过校验后，按原规则采用并清除旧轨迹。还有未应用草稿时，单步/运行会定位到该源并提示先应用或恢复，避免误用旧规律。

工程文件只保存已应用配置，草稿保留在本页会话中，保存提示会说明未写入草稿。新建/打开/导入/采用复算工程会清理旧工程草稿；已应用类型/波形改变后不串用旧草稿。参数运行中锁定。现有未知字段、来源、端口限制、原子失败及保存重跑检查保持。

## 工程读取顺序

同版修正连续打开工程/导入Control Sheet的读取竞争：按最后一次文件选择处理，过期成功/失败不覆盖当前工程、提示或新文件选择；最新失败保留当前组态，不回退采用旧请求。新建、示例及复算结果采用会使旧读取失效。运行前后均检查打开项目是否允许，拒绝时不假报已打开。导入解释、主图人工选择与语义确认规则不变。

## 笔记本窗口

0.46.2限制输入区高度不超过主区域的剩余空间，避免短窗口越过底部状态栏。常见笔记本宽度保持表单与预览两列，低于850像素高时图面缩为160像素。1280×720、1366×768可在输入页内滚动，将时刻/值和完整波形同时放在可见区域；应用按钮保持在页内底部。原图对照打开时仍为上方预留空间。
