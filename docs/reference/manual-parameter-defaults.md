# 导入时采用手册参数默认值

0.59.0核对REF_1100已实现的全部52种算法，登记202项明确的组态参数默认值。逐算法、逐参数的值、原表行、章节、手册页码、拆分PDF页码及原文件SHA-256见审查清单。原始资料保持只读。

SVG/MCR/TFT导入先采用明确配置，再为真正缺席的参数补齐手册默认值。右侧属性的“导入采用手册默认值”可展开查看；后来人工修改的参数会标出当前值。工程保存这些依据，导入核对清单的parameterDefaults另外保留当时的采用快照。新建块的可运行示例预设与手册默认值分别管理，不把示例预设套到导入块。

| 情况 | 导入处理 |
| --- | --- |
| 字段未出现，手册明确给出默认值 | 补齐并记录采用值、手册章节和页码 |
| 明确数值或0值 | 保留文件中的值 |
| 无效值、空属性、重复候选、来源冲突 | 保留诊断，不改用默认值 |
| 已由引脚驱动的可选择参数 | 保留信号连接，不补固定参数值 |
| 手册默认值为“-” | 不猜数值，继续明确缺参 |
| 不支持的默认模式或不能运行的默认数量 | 保留真实默认值，由运行前检查说明限制 |

重点差异：COUNTER.DRCT默认0；HIGHLOWMON.HISP默认0；SELECTOR.NMIN、DIGCOUNT.NMIN/MTRU和INTERP.NUMR默认0；INTERP的X1～X10默认均为0。输入数量0仍需要配置为有效数量。TRANSFER.OTRK默认ON，当前仅实现无跟踪的OFF模式，因此导入后明确提示模式限制；用户须按实际工况配置，程序不自动改为OFF。BCDNIN.BITP没有手册默认值，仍需指定起始位。

TRANSFER的SLEW、OTRK可从同名SVG/MCR属性恢复；不把整字节TFT的X1猜拆成两个选项。手册明确的枚举值作等价表示：INTERP的“线性”保存为LINEAR，BCD的“直接”保存为0，GAINBIAS的PROQ=ON保存为1。

AND/OR没有数值参数表中的输入数量默认值：其软件布局先按必选IN1/IN2生成，再按明确端口配置恢复可选输入。ASSIGN及INPUT/OUTPUT的信号类型依据端口、连线和点记录推导，外部输入波形仍由用户设置。ControlMacroReference继续仅还原接口和连线，不套用同名标准算法参数。

这项规则适用于新导入，不自动改写旧保存工程、人工修订值或历史运行记录。旧工程可保留备份后重新导入来源，取得默认参数和依据。运行快照与软件仿真起点仍分别处理：TFT中的ACT运行读数不作为仿真初态，手册组态参数默认值也不用于猜测OUT记忆状态或上一拍输入。

手册FUNCTION中Y8行名称误排为Y-9，但同一行T2字段与“Y-坐标8”描述一致；审查清单明确记录这一点，默认值0.0没有冲突。TRANSLATOR若干字段拼写异常只按具名参数读取默认值，不据此新增未经核实的TFT字段映射。
