# HIGHMON / LOWMON 监视块模型 v1

当前更新：核心0.8.0使用v2模型，在以下原扫描/分步运算规则之外增加已识别精度候选核对；候选结果或小目标分支不同则停止，不再把原v1的单一预测作为有效结果。见`precision-validation.md`。本文后续v1说明保留为规则沿革，合法且无分歧的计算不改。

依据本地REF_1100（2006-05）§4.46 p187、§4.59 p219。已直接核对原PDF的描述、符号、定义表与伪代码。产品/核心0.7.0；模型名`ref1100-2006-monitor-v1`，尚无Ovation运行对照。

## 固定类型与可选限值

|算法|模拟输入|数字输出|常量参数|记录字段|
|---|---|---|---|---|
|HIGHMON|IN1、可选HISP|OUT|未接HISP时的HISP、HIDB|HISP=R1，HIDB=R2|
|LOWMON|IN1、可选LOSP|OUT|未接LOSP时的LOSP、LODB|LOSP=R1，LODB=R2|

限值引脚未接线时必须有显式固定值；接线后读取该扫描按公开顺序可见的限值，不要求额外固定值。固定值若仍保留则明确不参与当前计算，属性禁用；断线后重新使用已保存固定值，缺值时阻断。HIDB/LODB为常量死区。所有引脚类型固定，不允许数字信号混入模拟引脚。

参数来源映射、宏公开参数覆盖不能向已接线的限值写入无效固定覆盖。用户需明确修复定义或连线。固定值改用测试源时复制现有值，避免无提示地改成0。

## 判断、保持与初态

HIGHMON：先判断IN1 > HISP，成立则TRUE；否则判断IN1 < HISP-HIDB，成立则FALSE；都不成立则保持上次OUT。

LOWMON：先判断IN1 < LOSP，成立则TRUE；否则判断IN1 > LOSP+LODB，成立则FALSE；都不成立则保持上次OUT。

两个比较均严格，不是大于等于/小于等于。零死区的等值点保留历史；负死区仍按书面伪代码的先后顺序判断，不擅自取绝对值或钳制。动态限值每拍重新读取，保持的输出来自上一已提交扫描。

必须显式给出布尔OUT初值；软件t=0快照不执行算法。memory仅为本软件用于观察的保持状态，与OUT同步，不声称是控制器内部记录字段。复位恢复所配置软件初态，不等同控制器冷/热重启。实例状态隔离，错误扫描整拍回滚。

## 数值及质量边界

输入、当前有效限值和死区转换为正常有限Float32（允许0）。进入第二分支时先将差/和舍入为Float32，再严格比较。这一中间精度是本软件明确的数值合同；手册未说明内部中间舍入，尚未用现场结果验证。不能据独立binary32向量声称与Ovation逐位等价。

手册对无效IN1规定保持最后值并将OUT质量置BAD，不传播IN1质量。当前正常有限数/GOOD受限profile不实现该质量路径：无效数、溢出/次正规结果、非GOOD质量或未知模式明确报错，保留上一完整扫描，不把它们模拟成一个正常FALSE或正常保持值。

## 核对向量与示例

HIGHMON固定HISP10/HIDB2、初态FALSE，输入10、11、10、8、7、10，对应OUT为FALSE、TRUE、TRUE、TRUE、FALSE、FALSE。LOWMON固定LOSP10/LODB2、初态FALSE，输入10、9、10、12、13、10，得到同一布尔序列。等于跳闸/复位边界均保持。

`examples/hysteresis-monitors.json`包含动态高限、固定低限、两台示波器。IN1初始9；高限按10→8→10→11→12变化，死区均2，低限10。0.6秒高限11使复位界限恰为9，OUT仍保持TRUE；0.8秒高限12后OUT才清除。0.9秒输入13，低限输出复位；1.0秒输入回9又置位。

`monitor-numeric-vectors.json`由独立Python struct生成12组位模式和手工边界期望值，包含半ULP舍入及相邻Float32输入。`tools/check-monitor-vectors.py`不导入模拟器代码。所有布尔结果精确比较；这些是软件数值模型证据，非现场采集。

现有真实来源HIGHMON/LOWMON的参数和类型可进一步恢复，但候选连线、未知字段、初态、工况和反馈限制继续保留，不表示整份真实宏已可准确运行。
