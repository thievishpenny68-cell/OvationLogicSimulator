# 输入输出名称与画布选择

0.48.0增加INPUT/OUTPUT独立命名和默认左键框选。核心仍0.28.0，信号类型、运算、输入时间、连线及逐拍记录规则保持。

## 按名称选择输入输出

选中INPUT或OUTPUT，在右侧属性区的“模块名称”填写名称并点击“保存名称”（0.49.0将INPUT基本属性移回右侧）。名称不能为空，保存时去掉首尾空格。改名即时更新画布、输入源下拉框、输出点状态总览、逐扫描/对照信号选择和示波器通道。

选择项通常使用模块名；若同名，则附加内部节点标识消歧。名称可以重复，重复名称不会合并信号或改变连线。内部绑定和CSV/JSON参考仍使用稳定的节点ID与字段，避免改名后旧记录或探针指向别处。

“保存名称”只更改显示信息，保留当前扫描、历史、输入波形草稿和观察选择，支持撤销/重做。运行中也可命名；其他逻辑参数仍锁定。保存工程包含新名称；已有运行记录保留当时的工程快照，重新打开工程运行时采用保存的名称和原有规则。

## 左键框选、中键平移

- 在画布空白处按住左键拖动，即显示矩形选框。松开后选中完整落入矩形的控制块，可以反向拖动。
- 普通框选替换之前选择；按住Shift框选追加，Shift点选增减单块。点击空白清空选择。
- 拖动任一已选块可以移动整组；撤销一次还原组移动，运行记录保持。删除所选块按原逻辑修改规则清旧轨迹。
- 按住滚轮（中键）并拖动平移画布；可以从空白、模块、连线或示波器上开始。滚动滚轮仍为缩放。
- Escape、指针取消或窗口失焦取消未完成的框选/移动/平移，恢复原选择、位置或视图。

鼠标位置使用SVG实际屏幕变换换算，输入页展开或留白不会使选框与模块错位。原SVG只读对照区域保持其既有浏览方式；以上鼠标分工用于可编辑组态画布。
