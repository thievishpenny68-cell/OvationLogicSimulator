# 源对象属性与缺失动态文字

产品0.7.1，核心仍0.7.0，算法/扫描/数值模型不变。

在“检查与导入问题”点“查看原SVG”或候选的“对照源图”。点击源图图元，下方“所选源对象 · 原始属性”显示所选标签、ID、原属性、引脚/算法祖先及所在上下文的空DynamicText编码。原属性按文字展示，不执行其中的脚本、资源或事件。

“放大源对象”可在原图聚焦所选对象；“整张原图”恢复全图。

有已有的来源/布局对应时，可点击“定位”选择编辑块并调整画布。此操作只用于布局核对，不代表对象、针脚或参数已经准确识别。多个宏实例的同一源对象列出多个选择，不自动选一份；原图ID重复/缺失或文件不匹配时不猜测关联。

新导入明确保存provenance.svgSourceFile；旧工程可以从已有的SVG字段来源/原目标信息兼容关联。有明确SVG来源时优先使用它，当前工程文件名不能覆盖另一个明确来源。没有足够信息时仍可看原属性，按外部资料人工核对。

拖动超过点击阈值仍为源图平移，取消恢复视图。查看和布局定位不会新增/采用候选、改变参数/初态/连线、改写原始审计、清空运行或覆盖正在填写的补线草稿。核对之后仍需在原有修复面板明确端口及依据，再采用连接。

真实资料中大量DynamicText只有编码cb-source，子text/tspan无可显示正文。预览明确报告这些缺失项，保留编码供核对；不生成假点名，不按属性值相等或位置猜测针脚。静态正文照常显示，预览不声称完全还原CB Editor动态标签。应结合实际CB Editor结果、原记录及手册核对。

`docs/validation/source-preview-structure.json`独立统计原SVG图元、连接和缺失动态文字，逐元素比对原始属性；没有用成功显示数量代替原始分母。该报告仅证明所列结构与属性保留，不证明像素一致或仿真语义通过。

当前4份标准SVG合计960个基本图元、72个连接实例、1686个源元素。空DynamicText分别为21、47、78、43项，共189项；每个源元素的原属性均逐项核对。保留原始SHA256及所列限制，不将空正文推断为0值、FALSE或已知点名。
