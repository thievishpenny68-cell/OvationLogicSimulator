# 常数与索引存储（0.25.0）

本批新增3种基本模块，共43种可执行手册算法；核心0.16.0。沿用GOOD质量、正常有限Float32、显式软件起点和精度检查合同。软件tick 0是执行前显式初态，首扫描才执行算法，不等同控制器初始化过程。

|模块|手册依据|参数与行为|实际针脚/记录许可|
|---|---|---|---|
|AVALGEN|§4.15 p47|VALU为实数整定常数，默认0；每扫描OUT=VALU|无输入；OUT模拟LA|
|DVALGEN|§4.36 p158|VALU为实数整定常数，默认1；0为FALSE，任意非零实数为TRUE|无输入；OUT数字LD/LP|
|TRNSFINDX|§4.121 p417～418|NMIN为1～64的输出数量；IN2选路，只把IN1写入所选输出，其余保持|IN1、IN2及O01～O64均模拟LA|

DVALGEN的VALU是手册定义的实数参数，可输入负数或非1的非零数；数字输出仍严格为布尔值。缺参数、非数值、无效数或超出当前Float32范围明确拒绝。导入只采用明确VALU/VALUE属性或表中的R1，不补默认常数。

TRNSFINDX支持全部64路和逐路显式初态。索引<=0或>NMIN时不写入；有效范围内仅执行整数索引，分数索引的取整规则未见手册定义，因此停止并保留整拍原状态，不猜floor或四舍五入。改变NMIN同步改变实际针脚、图例和初态表单；减少数量时明确提示移除不再选用输出的初值，可撤销，原连接保留并报缺失端口供人工核对。新增输出的初态须明确补齐。

所有外形、内部标记和引脚方向取自原手册：AVALGEN为A字菱形、底部模拟输出；DVALGEN采用手册允许的矩形/底部数字输出；TRNSFINDX采用长矩形、左侧IN1与IN2(INDEX)、右侧O编号输出。输入/输出端点继续按类型显示，针脚许可纳入统一类型校验。LP执行范围未扩展。

打开`examples/simple-sources-storage.json`，周期250ms，单步6次。两台示波器分别观察三个存储输出和两个常数。最后应为AVALGEN=-2.5、DVALGEN=TRUE、O01=60、O02=70、O03=30。静态参考`examples/simple-sources-storage-reference.json`以手册公式和字面量独立编写，未调用模拟引擎生成。

在信号总览清空默认选择，只选analog.OUT、digital.OUT及store.O01/O02/O03，再载入参考，以“人工整理”和零容差对照，应有35/35项一致。保存重开、逐拍复跑、完整运行记录复算均覆盖；该证据是软件与手册规则验证，没有新增Ovation现场采集。

本批暂缓：ANTILOG的超范围限幅边界未明确；RATEMON的TS单位未取得明确依据；MEDIANSEL/QAVERAGE需要核心质量选路；RATECHANGE旧平滑状态未清；RATELIMIT公式/等号存在矛盾；RUNAVERAGE首拍要求BAD；SMOOTH未给精确递推式。没有用常见公式替代手册空缺。
