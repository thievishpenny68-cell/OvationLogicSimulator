# 手册符号与FIFO示波器

0.20.0更新显示与交互；仿真核心仍0.12.0，算法、初态、引脚类型、扫描模型及记录数值不变。

## 控制块

当前20种已支持原厂算法及PACK16/UNPACK16两个已识别接口，按本地REF_1100（2006-05）“功能符号”重绘轮廓、内部标记、箭头、引脚方向和顺序。曲线门采用原PDF曲线坐标；矩形、圆形、内部斜线与脉冲为原生SVG，可随画布缩放。左侧控制块预览同步使用手册符号。

例如AND是D形、OR是带左侧输入母线的圆圈、NOT是矩形内N，XOR为双弧门；不能套用其他品牌的常见OR/NOT图标。算术/高低选的输入在上、OUT在下；监视块HISP/LOSP在IN1上方；AAFLIPFLOP的INIT在下方。三种定时器TARG在左、ACT在右，BASE不作为针脚画出。

灰色针脚标签表示未选用或当前未支持，不能接线；可悬停查看原因。TARG用固定参数形式显示，应在属性区配置，不因此开放动态输入。PACK/UNPACK保持手册长矩形，省略位展开为16个按编号排列的真实接口，原来的禁止执行边界保留。

软件输入/输出和示波器属于自建工具；未识别块、宏占位继续明确提示，不套用同名原厂算法符号。新几何不写入项目，不改变参数或运行记录。手册符号需要的空间与旧卡片不同，旧项目可拖动整理后“适应画布”；接线、观察探针、拖线预览、框选和画布适应均使用同一组真实锚点。已随新外形调整两个基本块示例的显示间距。没有坐标的SVG导入使用更宽的自动间距，原SVG明确给出的坐标及旧项目保存的位置保留。

## 示波器

选定时间窗W后，横轴刻度固定为0、W/2、W秒。开始时从0向右填充已有数据，不再每拍把短曲线拉伸到全宽。时间超过W后，曲线整体向左移动，旧数据从左侧退出，新数据在右侧进入，按FIFO窗口显示；刻度本身仍为0..W。

顶部“扫描… · 起点–终点s”显示这段窗口对应的实际仿真时间。例如1秒窗口在仿真1.1秒时，顶部显示0.1–1.1s，横轴仍0–1s。回看历史时使用所选扫描当时的窗口，不显示未来数据。

“全程上限”保留旧项目中windowSeconds=0的配置，但把最大刻度固定为本次最多允许扫描的总时长；默认周期0.1秒、最多10000扫描时为1000秒。短工况可选1秒或5秒窗口，以便清楚观察。

FIFO仅影响示波器的显示窗口，完整历史、CSV/JSON导出和复算不删除采样。数字保持阶梯、模拟保持采样连线，缺值断线保留；底部全局趋势仍用于浏览整段历史。
