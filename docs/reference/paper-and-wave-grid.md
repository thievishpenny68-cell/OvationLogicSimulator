# 画纸边界与多列切换节点

0.51.0在底部页签增加“画纸设置”，同时让分段输入节点利用预览左侧的可用宽度。

## 切换节点向右排列

分段保持、分段线性的节点按从左到右、再到下一行排列。宽屏可同时编辑多列，窄窗口自动减少列数；增加、删除节点与保存的数据顺序保持一致。每个节点仍独立填写时刻和值，数字量仍只给TRUE/FALSE。常量、阶跃、斜坡的普通字段保持紧凑；右侧波形预览保留。

## 画纸设置

底部“画纸设置”可填写左边界、上边界、宽度和高度，单位为画布单位，与屏幕像素及打印毫米无固定换算。宽高须为正数，位置可为负数。可选择虚线或实线，并切换边界显隐。

- “应用画纸设置”：更新边界与画纸区域。
- “包围全部内容”：按模块及示波器外框重新确定边界，四周留出余量。
- “查看整张画纸”：调整观察视图，使四边可见。顶部“适应画布”仍按逻辑内容定位。

边界用于提示排布范围，设置页列出超出范围的对象。画纸调整保留对象坐标和连接，运行与输入草稿也保持；边界外对象仍可查看和编辑。

默认画纸为3600×2400画布单位（0.51.1起）。旧工程未设置画纸时，根据首次打开的内容确定默认范围，超大内容可扩展范围，在本次打开期间固定。已保存的自定义画纸保持原尺寸。应用设置或包围内容后，配置以工程顶层paper字段保存，可保存重开及撤销/重做。默认边界不会为未编辑的旧工程增加字段。完整指纹包含paper，计算投影剔除此显示字段；原有算法、时序和点类型规则保持。

可打开examples/paper-and-wave-grid.json，分别查看多列切换节点和画纸设置。

0.54.0起，带 IncludeDocument 原图框的 SVG 导入使用源图纸的有效尺寸；图框在右下角按比例放置，调整画纸会重定位图框。新建空白工程仍默认3600×2400，已保存的自定义尺寸保持。
